# 力场渲染清晰度优化 — 工业方案调研

## 当前问题
用户反馈：力场颜色"雾蒙蒙"，清晰度不够，颜色不够锐利。

## 工业成熟做法

### 1. 感知均匀色带（最易实现 ★）
科学色带（matplotlib viridis/plasma/inferno）经过感知均匀性设计，同等数据变化产生同等视觉变化，不会某段"糊"某段"跳"。

| 色带 | 低→高 | 特点 |
|------|-------|------|
| **Viridis** | 深紫→蓝→绿→黄 | 最流行，色盲友好 |
| **Inferno** | 黑→暗红→橙→黄→白 | 高对比度，热感强 |
| **Plasma** | 深紫→粉→橙→黄 | 鲜艳醒目 |

**改动**：shader中替换heatColor的5个颜色值为对应色带的采样点。

---

### 2. 增加光照（性价比最高 ★★★）
当前壳层ShaderMaterial是**平板着色**（无光照），视觉上像"贴纸"糊在模型上。

加上简单Phong光照：
```glsl
// 壳层shader中加入光照
vec3 N = normalize(vWorldNormal);
float NdotL = max(dot(N, lightDir), 0.0);
vec3 lit = heatColor(t) * (0.3 + 0.7 * NdotL); // 30%环境光+70%漫反射
```

**效果**：
- 曲面起伏可见 → 3D立体感
- 暗面自然变暗 → 深浅层次
- 消除"平面贴纸"感

**改动**：壳层shader + 壳层几何体需传法线（顶点着色器已传但片段没用）。

---

### 3. 离散色带（工程风格）
像ANSYS/Abaqus后处理：5-8个离散颜色等级，每级有明确边界。

```
t=0.0-0.2: 深蓝    t=0.2-0.4: 蓝
t=0.4-0.6: 绿      t=0.6-0.8: 黄
t=0.8-1.0: 红
```

**效果**：压力值一目了然，专业感强。

---

### 4. 离散色带+等高线
在离散色带基础上叠加等高线（isoline），FEA/CFD行业标准。

**改动**：复杂，需额外shader pass。

---

### 5. 高光Bloom效果
渲染后对高亮区域做模糊+叠加，产生"发光"效果。游戏/数据可视化常用。

**改动**：需额外后处理pass，Chromium 83兼容性需验证。

---

### 6. 锐化alpha曲线
当前 `cf = min(mw*2.0, 1.0)` 线性过渡。改为非线性曲线让中心更实、边缘更利：

```glsl
float cf = smoothstep(0.0, 1.0, pow(mw, 0.5)); // 更陡的过渡
// 或
float cf = mw > 0.3 ? 1.0 : mw / 0.3; // 阈值式
```

---

## 推荐组合

| 优先级 | 方案 | 工作量 | 效果 |
|--------|------|--------|------|
| **立即做** | 感知均匀色带(Inferno) | 改5个颜色值 | 去雾明显 |
| **立即做** | 壳层加光照 | ~5行GLSL | 立体感立现 |
| **备选** | 锐化alpha | 改1行 | 边缘更利 |

**Inferno + 光照**组合预期效果：高对比暖色热力图 + 曲面光影 → 清晰不糊。
