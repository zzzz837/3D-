# v1.0.1 开发需求文档：稳定演示版

当前 v1.0.0 已经完成 Cell 编辑、手动压力、模拟压力、Wendland 力场预览、性能优化、工程保存/加载等核心能力。v1.0.1 不再扩展 MLS、Graph、真实 ADC、时间序列导入等新方向，本版本目标是把现有软件打磨成更稳定、更流畅、更适合演示的版本。

1. 移除“导入数据”功能。本版本只保留“手动压力”和“模拟压力”两种模式，删除“导入数据”按钮、导入数据模式、real mode、importFieldJSON、_importedField 以及所有未使用的导入数据相关 UI 和代码。真实 ADC 或数据文件导入后续版本再重新设计，不要在 v1.0.1 保留半成品入口。

2. 增加超大模型自动降采样。导入 3D 模型后自动检测 vertexCount / faceCount，如果模型复杂度过高，自动进行降采样以提升加载、预览和力场渲染性能。建议阈值：20 万面以下不处理；20–50 万面轻度降采样，目标保留约 70%；50–100 万面中度降采样，目标保留约 40%；100 万面以上重度降采样，目标保留约 20%–30%。降采样后的模型用于渲染、Cell 放置和力场预览，要求尽量保持外形、法线和 Cell 放置精度。右侧模型信息中显示“原始面数、降采样后面数、压缩比例”，并在导入时给出提示，例如“检测到超大模型，已自动降采样：1498770 → 320000 faces”。

3. 重做模拟压力逻辑。模拟模式下不要再使用随机变化或无规律跳变，而是使用连续、平滑、可预测的正弦波压力变化。每个 Cell 的 pressure 由 base、amplitude、frequency、phase 共同决定，例如 `pressure = base + amplitude * sin(2π * frequency * time + phase)`，不同 Cell 使用不同 phase，使压力变化呈现自然的波动感，而不是所有点同时变化或随机闪烁。模拟 pressure 只能写入 `C[id].pressure`，Mesh 热力图仍然必须经过 Wendland 重建和 vertex color 更新，不允许绕过 Wendland 直接给 Mesh 上色。

4. 优化模拟动画帧率。模拟模式需要更流畅，但不要追求 60FPS。建议使用 `requestAnimationFrame` 加时间间隔控制，目标刷新 20–30FPS；如果实现不方便，也可以使用 33–50ms timer。压力变化必须基于真实 elapsed time / deltaTime，而不是固定帧计数，避免帧率波动导致动画忽快忽慢。手动压力模式不允许启动定时刷新，只有模拟压力开启时才进行低频连续更新。

5. 增加模拟压力预设。模拟模式下增加 3 个预设：Uniform、Wave、Pulse。Uniform 表示所有 Cell 同步按正弦波变化，适合展示整体受压；Wave 表示 Cell 根据位置或 ID 产生相位差，形成波浪传播效果，作为默认模式；Pulse 表示局部或若干 Cell 周期性增强，适合展示局部压力脉冲。三个预设都必须输出到统一的 `C[id].pressure`，不能各自绕过现有力场链路。

6. ：保留并保护现有已通过能力。不要改动已经验收通过的 Wendland 核心公式、Influence Cache、手动压力输入、pressure 保存恢复、力场半径、coverage mask、增强颜色映射等逻辑。v1.0.1 的开发重点是删减未成熟功能、改善大模型处理、优化模拟演示效果，不是重写力场算法。

验收标准：第一，界面中只剩“手动压力”和“模拟压力”，不再出现导入数据相关入口；第二，导入 100 万面以上模型时能够自动降采样并显示降采样信息，导入和预览明显更流畅；第三，模拟压力变化连续、平滑、有规律，不再随机跳变；第四，Wave 模式下可以看到压力像波一样在不同 Cell 间变化；第五，Pulse 模式下可以看到局部压力周期性增强；第六，手动模式下 pressure 静止不变，修改数值后才刷新；第七，模拟模式连续运行 3–5 分钟不卡死、不明显掉帧；第八，保存和重新打开项目后 Cell、pressure、模型仍然正常。

本版本不开发：真实 ADC 接入、CSV/JSON 数据导入、时间序列回放、时间轴、MLS、Graph Laplacian、GPU Shader 重构、WebGPU、多线程计算。这些全部放到后续版本，不要混入 v1.0.1。
