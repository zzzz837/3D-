## 九、自动吸附

### 旧版

放置 Cell 时检测 2.5×半径内已有 Cell，沿 X / Y 全局坐标自动吸附到相切。

### 当前改进

- 吸附不再沿全局 X / Y，而是在**放置点曲面切平面**中构建 `hDir / vDir`
- 针对每个邻居生成 4 个网格候选（左 / 右 / 上 / 下）
- 每个候选先在切平面生成，再通过 BVH `closestPointToPoint` 投影回曲面
- 对投影后的 3D 中心距做验证，避免直接重叠
- 仅从通过验证的候选中选择最接近光标的位置

> 目标：在任意曲面上实现“沿曲面网格排列 + 相邻 Cell 精确相切”的放置体验。

## 十、Cell 曲面贴合

### 旧版问题

- 所有顶点统一按 Cell 中心法线偏移
- 弯曲面上不同顶点贴到不同法线的面片时会歪斜、扭曲、甚至重叠
- `maxJump` 过大时外圈顶点容易跳到错误面片

### 当前改进

- 新增 `_getSurfaceNormal()`：逐顶点通过射线获取局部曲面法线
- 每个顶点改为沿自身局部曲面法线偏移，而不是统一用中心法线
- 加入法线一致性检查 `dot > 0.3`，法线差异过大则拒绝该投影
- `maxJump` 从 `ru*6 / 80mm` 收紧到 `ru*3 / 25mm`
- 任何顶点失败时，整块圆盘回退到平面圆盘，避免半投影半塌缩

## 十三、关闭软件保存弹窗

### 需求调整

只要已经加载过模型 / 项目（无论是否修改），点击关闭都必须弹出保存对话框。

### 当前实现

- 新增 `_has_open_project()`，不再单独依赖 `_dirty`
- 只要满足以下任一条件即视为“已有项目”：
  - `_model_cache_path` 存在
  - `_current_file` 存在
  - `_project_info['name']` 存在
  - `_model_loaded == True`
- 关闭弹窗统一为：
  - `保存`
  - `不保存`
  - `取消`
- 关闭前保存使用异步导出；保存成功后通过 `_close_after_save` 直接关闭，不再二次弹窗
- 增加 `close-check / close-dialog-result / closeEvent` 日志，便于排查关闭链路问题
