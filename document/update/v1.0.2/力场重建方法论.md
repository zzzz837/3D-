# 3D曲面力场重建方法论

> 本文档描述一套完整的、自包含的力场重建方法，适用于在3D曲面上布置离散压力传感器（Cell）的场景。给定一组贴附在3D模型表面的传感器位置和压力读数，重建连续压力场并可视化呈现。

---

## 1. 问题定义

### 1.1 输入

| 输入 | 类型 | 说明 |
|------|------|------|
| 3D网格模型 | `BufferGeometry` | STL/OBJ导入的三角网格，每个顶点有位置和法线 |
| Cell集合 | `Array<Cell>` | 每个Cell包含：3D位置 `(x,y,z)`、法线 `(nx,ny,nz)`、半径 `r`、压力值 `pressure ∈ [0,1]` |
| 单位比例 | `unitMM` | 1模型单位对应多少毫米（STL单位检测：米→1000，厘米→100） |

### 1.2 输出

一个覆盖整个模型表面的点云，其中：
- 每个点的**空间位置**在曲面上均匀分布
- 每个点的**颜色**由Jet色带映射压力值
- 每个点沿法线方向的**高度位移**正比于压力值

### 1.3 核心原则

**传感器是连续场的离散采样点，不是力源。** 压力场在传感器之间存在连续分布，重建算法应当是从离散采样反推连续场，而非从传感器向外发射。

---

## 2. 数学基础

### 2.1 Wendland C² 紧支撑径向基函数

选择 Wendland C² 核作为权重函数：

$$\varphi(r) = \begin{cases} (1-r)^4(4r+1) & r < 1 \\ 0 & r \geq 1 \end{cases}$$

其中 $r = d / R$，$d$ 为顶点到Cell的3D欧氏距离，$R$ 为查询半径（支撑半径）。

**选择理由：**
- **紧支撑**：$r \geq 1$ 时严格为0，影响范围有限，适合空间分桶加速
- **C²光滑**：函数及其一阶、二阶导数在 $r=1$ 处连续，重建场无梯度突变
- **严格正定**：保证加权插值的良态性
- **单调递减**：距离越近权重越大，符合物理直觉

### 2.2 加权平均重建公式

对于模型表面上的任意顶点 $v$，其压力重建值：

$$P(v) = \frac{\sum_{i} P_i \cdot \varphi(r_i)}{\sum_{i} \varphi(r_i)}$$

其中：
- $P_i$ 是第 $i$ 个Cell的传感器压力读数（真实值，非伪造值）
- $r_i = \|v - c_i\| / R$，$c_i$ 是第 $i$ 个Cell的3D位置
- 求和遍历所有 $\varphi(r_i) > 0$ 的Cell（即在支撑半径内）

### 2.3 法线兼容性过滤

为防止穿过模型背面的Cell影响正面顶点（"串色"），引入法线点积过滤：

$$\vec{n}_v \cdot \vec{n}_{c_i} \geq \tau_n$$

其中 $\vec{n}_v$ 是顶点法线，$\vec{n}_{c_i}$ 是Cell法线，$\tau_n = 0.1$（宽松阈值，仅排除近乎正对的背面）。

## 3. 查询半径自动计算

查询半径 $R$ 决定每个Cell的影响范围。过小导致Cell间出现空洞（色斑），过大导致过度平滑。自动计算公式：

$$R_{eff} = \max(R_{base},\ R_{cell} \times 1.2,\ D_{nn} \times 3)$$

其中：
- $R_{base}$：用户配置的基础半径（默认60mm）
- $R_{cell}$：最大Cell半径
- $D_{nn}$：所有Cell之间的最近邻距离（O(N²)计算，N为Cell数量）

**3倍最近邻距离**保证相邻Cell的Wendland影响区有充分重叠——在两Cell连线中点处，两个 $\varphi$ 值都处于较高区间，加权平均后得到平滑过渡，而非各自独立的色斑。

## 4. 网格自适应细分

### 4.1 问题

原始STL模型的顶点密度可能不足以支撑力场重建——如果模型最大边长（mm）远大于查询半径，则Cell影响区内的顶点太少，重建场会出现锯齿。

### 4.2 细分决策

计算模型最大边长 $E_{max}$（mm），目标边长 $E_{target} = \max(R/4, 1\text{mm})$：

| 条件 | 细分级别 |
|------|----------|
| $E_{max} > E_{target} \times 2.5$ | Level 2（四倍细分） |
| $E_{max} > E_{target} \times 1.2$ | Level 1（二倍细分） |
| 否则 | Level 0（不细分） |

**上限保护**：细分后顶点数不超过200,000，若超过则降低级别。

### 4.3 细分算法

对每个三角形，取三条边的中点，生成4个子三角形：

```
        C
       / \
      /   \
    CA------BC
    / \   / \
   /   \ /   \
  A-----AB-----B
```

中点通过共享缓存去重（边 `(a,b)` 的中点只计算一次），保持索引拓扑。

### 4.4 Laplacian平滑

细分后执行与细分级别等次数的Laplacian平滑，消除细分产生的棱角：

$$v_i' = v_i + \lambda \cdot \frac{\sum_{j \in N(i)} w_{ij} (v_j - v_i)}{\sum_{j \in N(i)} w_{ij}}$$

其中：
- $N(i)$ 是顶点 $i$ 的邻接顶点集合（从三角面索引构建）
- $w_{ij} = \max(0, \vec{n}_i \cdot \vec{n}_j)$：法线加权，防止跨越折边/尖角的平滑扩散
- $\lambda = 0.5$：平滑强度

每次平滑后重新计算法线，保证后续重建精度。

## 5. 空间分桶加速

### 5.1 问题

重建需遍历所有密集网格顶点 $V$，每个顶点查询所有Cell $N$。朴素实现为 $O(V \times N)$，当 $V=150{,}000$、$N=22$ 时约330万次距离计算。

### 5.2 3D均匀网格分桶

将Cell按位置放入3D均匀网格，桶尺寸 = 查询半径 $R$：

1. **构建**：计算Cell的AABB包围盒，扩展 $0.1R$ 余量，按 $R$ 划分为 $n_x \times n_y \times n_z$ 个桶
2. **查询**：给定顶点位置，计算其所在桶坐标 $(b_x, b_y, b_z)$，搜索 $3 \times 3 \times 3$ 邻域桶中的Cell

**复杂度**：$O(V \times k)$，其中 $k$ 是每桶平均Cell数（通常远小于 $N$）。

## 6. 重建管线

### 6.1 输入准备

1. 收集所有Cell的压力值 `cellPressures`
2. 过滤出 $P_i > 0$ 的活跃Cell
3. 构建Cell数据数组：`{x, y, z, p, nx, ny, nz}`

### 6.2 重建循环

```
for 每个密集网格顶点 v_i:
    lx, ly, lz = v_i.position
    vnx, vny, vnz = v_i.normal
    neighbors = queryBucketCells(lx, ly, lz)   // 空间分桶查询
    num = 0, den = 0
    for 每个 Cell c in neighbors:
        d = distance(v_i, c)
        if d > R: continue                      // 超出支撑半径
        r = d / R
        nd = dot(v_normal, c_normal)
        if nd < 0.1: continue                   // 法线不兼容（背面）
        w = wendlandPhi(r)                      // Wendland C² 权重
        if w <= 1e-8: continue
        num += c.p * w                          // 加权分子
        den += w                                // 加权分母
    if den > 1e-6:
        scalars[i] = clamp(num / den, 0, 1)     // 归一化压力值
```

### 6.3 输出

- `scalars: Float32Array[nVerts]` — 每个顶点的重建压力值 ∈ [0,1]
- `coverage: Float32Array[nVerts]` — 覆盖度（$\sum w$，可用于调试）
- `covered: Uint32Array` — 有力场值的顶点索引列表

## 7. 点云渲染

### 7.1 设计理念

模型本身保持灰色半透明静态不动，力场通过覆盖在模型表面的**点云**展示：
- **均匀密度**：所有点始终可见（alpha=1.0），空间密度一致
- **高度编码力值**：沿法线位移，力值越大隆起越高
- **颜色编码力值**：Jet色带，深蓝(0)→蓝→青→绿→黄→橙→红(1)

### 7.2 子采样

密集网格可能有15万+顶点，全量渲染点云会产生性能问题和"密集层"视觉效果。采用等间隔子采样：

| 密集网格顶点数 | 子采样步长 | 结果点数 |
|----------------|-----------|----------|
| ≤ 2,000 | 1 | 全部 |
| ≤ 50,000 | 2 | 1/2 |
| > 50,000 | 3 | 1/3 |

子采样映射：点云第 $i$ 个点对应密集网格第 $i \times \text{subsample}$ 个顶点。

### 7.3 GPU ShaderMaterial

**顶点着色器**：
```glsl
attribute float alpha;
attribute vec3 aColor;
attribute float aField;
attribute vec3 aNormal;
uniform float uPointSize;
uniform float uBulgeHeight;
uniform float uPtScale;

void main() {
    vColor = aColor;
    vAlpha = alpha;
    // 沿法线位移: 力值 × 隆起高度
    vec3 displaced = position + aNormal * aField * uBulgeHeight;
    vec4 mvPosition = modelViewMatrix * vec4(displaced, 1.0);
    // 透视点大小: 近大远小
    gl_PointSize = uPointSize * (uPtScale / -mvPosition.z);
    gl_Position = projectionMatrix * mvPosition;
}
```

**片元着色器**：
```glsl
void main() {
    if (vAlpha < 0.01) discard;
    // 圆形点: 把方形成片裁剪为圆
    vec2 c = 2.0 * gl_PointCoord - 1.0;
    if (dot(c, c) > 1.0) discard;
    gl_FragColor = vec4(vColor, vAlpha);
}
```

**关键属性**：
- `transparent: true` + `depthWrite: false`：半透明叠加，避免深度冲突
- `uBulgeHeight`：最大隆起高度，默认 = 模型包围盒对角线 × 4%
- `uPtScale`：点大小透视缩放因子，默认 = 300 + 对角线 × 50

### 7.4 逐帧属性更新

当压力值变化时（模拟模式或手动输入），更新点云属性数组：

```
for 每个点云点 pi:
    vi = pi * subsample                // 映射到密集网格顶点
    s = scalars[vi] || 0
    aField[pi] = s                     // 力场值 → shader位移
    alpha[pi] = 1.0                    // 全部可见: 统一密度
    color = jetColorNew(s)             // Jet色带直接着色
    aColor[pi] = color
```

**设计要点**：
- 所有点 `alpha=1.0`，保证空间密度一致
- 零力值点显示为深蓝（Jet(0)），平面无位移——作为力场的"零基准"
- 有力值点显示为彩色，沿法线隆起——直观展示力的大小和分布
- 不使用灰色混合或阈值过滤，消除"半球喷出"、"密度不均"、"灰色点"三个问题

## 8. 色带定义

Jet色带（7段线性插值）：

| 压力值 | 颜色 | RGB |
|--------|------|-----|
| 0.00 | DeepBlue | (0, 0, 143) |
| 0.15 | Blue | (0, 0, 255) |
| 0.30 | Cyan | (0, 255, 255) |
| 0.45 | Green | (0, 255, 0) |
| 0.55 | Yellow | (255, 255, 0) |
| 0.70 | Orange | (255, 165, 0) |
| 1.00 | Red | (255, 0, 0) |

**选择理由**：冷暖渐变直观，色盲友好，工业可视化通用标准。

## 9. 用户可调参数

| 参数 | 范围 | 默认值 | 效果 |
|------|------|--------|------|
| 查询半径 R | 20-200mm | max(60, Cell半径×5) | Cell影响范围，增大→更平滑 |
| 隆起高度 | 0-200% | 100% | 点云沿法线位移幅度 |
| 点大小 | 1-200 | 80 (0.08) | 每个渲染点的像素尺寸 |

### 9.1 隆起高度

最大隆起量 = 模型包围盒对角线 × 4%。滑块百分比控制实际隆起占比。更新时直接修改shader uniform，无需重建几何——GPU即时反映。

### 9.2 点大小

实际点大小 `uPointSize = 0.01 + (百分比/100) × 0.19`。配合透视缩放因子 `uPtScale`，近处点大、远处点小，产生深度感。

## 10. 缓存与增量更新

### 10.1 几何缓存

| 数据 | 重建条件 | 生命周期 |
|------|----------|----------|
| 密集网格 `_denseGeo` | 模型几何变更 | 模型不变则复用 |
| 点云几何 `_pointsMesh` | 模型变更或首次创建 | 几何不变则复用 |
| 顶点邻接表 `_adj` | 模型几何变更 | 模型不变则复用 |
| 预览线框 `_previewWire` | 模型几何变更 | 模型不变则复用 |

### 10.2 重建缓存

压力值和查询半径的JSON指纹作为缓存键。如果压力值和半径都没变，跳过重建。这在模拟模式下每40ms触发更新时尤其重要——只有压力真正变化时才执行重建。

### 10.3 增量更新流程

```
updateHeatmap():
    1. 检查模型几何是否变更 → 是: 重建密集网格+点云
    2. 计算自动查询半径 R
    3. 检查压力值+半径指纹 → 未变: 直接返回
    4. reconstructOnDenseGeo() → 重建标量场
    5. updatePointCloudAttributes() → 更新点云属性
```

## 11. 模拟压力生成

支持三种预设模拟模式，用于无真实传感器时的演示：

### 11.1 Uniform（均匀脉动）

所有Cell同步在0.2-0.8之间正弦脉动：
$$P_i(t) = 0.2 + 0.6 \times \frac{1 + \sin(t)}{2}$$

### 11.2 Wave（行波）

每个Cell按不同频率和相位独立脉动：
$$P_i(t) = 0.15 + 0.7 \times \frac{1 + \sin(\omega_i t + \phi_i)}{2}$$

其中 $\omega_i = 0.3 + (i \bmod 7) \times 0.15$，$\phi_i = (i+1) \times 0.73$。

### 11.3 Pulse（脉冲热点）

每2.5秒随机选取15%的Cell作为热点，其余保持基线0.1：
$$P_{hot}(t) = 0.1 + 0.9 \times \sin^2(\pi \cdot t_{local})$$

## 12. 渲染状态切换

进入力场重建时，模型材质切换为灰色半透明基底：

| 属性 | 原始值 | 重建状态值 |
|------|--------|------------|
| color | 原模型色 | `0x7f8998`（灰） |
| opacity | 原始值 | `0.5` |
| transparent | 原始值 | `true` |
| flatShading | 原始值 | `true` |
| shininess | 原始值 | `3` |
| depthWrite | 原始值 | `true` |

同时叠加暗色线框（`0x333344`, opacity `0.12`）显示原始网格骨架。

退出时恢复原始材质属性，销毁点云和线框。

```
│                    力场重建完整管线                              │
└─────────────────────────────────────────────────────────────────┘

  Cell传感器 (位置+法线+压力)
       │
       ▼
  ┌─ 自动查询半径 R ─┐
  │  R = max(         │
  │    R_base,        │
  │    Cell半径×1.2,  │
  │    最近邻间距×3   │
  │  )                │
  └────────┬──────────┘
           │
           ▼
  ┌─ 空间分桶 ────────┐
  │  桶尺寸 = R       │
  │  3D均匀网格        │
  │  O(V×k) 查询      │
  └────────┬──────────┘
           │
  ┌─ 网格自适应细分 ──┐     ┌─ Wendland C² 重建 ──────┐
  │  E_max > R/4 ?    │     │  for 每个顶点 v:        │
  │  Y: 4倍细分×L     │────▶│    for 每个邻近Cell c:  │
  │  + Laplacian平滑  │     │      d=dist(v,c)       │
  │  (法线加权)        │     │      r=d/R             │
  └───────────────────┘     │      w=φ(r)=(1-r)⁴(4r+1)│
                            │      P(v)+=P_c×w        │

                            └──────────┬──────────────┘
                                       │
                            ┌─ 点云渲染 ──────────────┐
                            │  子采样 (1/2 或 1/3)    │
                            │  alpha=1.0 (全可见)     │
                            │  color=Jet(P(v))       │
                            │  displacement=P(v)×H   │

                            └──────────┬──────────────┘
                                       │
                                       ▼
                            ┌─ 可视化输出 ────────────┐
                            │  灰色模型(不动)        │
                            │  + 彩色点云(法线浮动)   │
                            │  + 暗色线框(骨架)      │
                            └────────────────────────┘
```

## 14. 关键设计决策总结

| 决策 | 选择 | 理由 |
|------|------|------|
| 核函数 | Wendland C² | 紧支撑+C²光滑+正定，适合GPU分桶加速 |
| 重建公式 | 加权平均 | 直接、稳定，无需求解线性方程组 |
| Cell数据 | 真实位置+压力 | 传感器是采样点不是力源，不伪造虚拟锚点 |
| 查询半径 | 自动3×最近邻 | 保证Cell间充分重叠，消除色斑 |
| 点云密度 | 全部可见 | 统一密度，通过高度+颜色展示力场 |
| 点云着色 | Jet直连 | 不混合灰色，消除歧义 |
| 位移方式 | GPU shader | 沿法线方向，模型本身不动 |
| 网格处理 | 自适应细分+平滑 | 保证顶点密度足以支撑重建 |
| 加速结构 | 3D均匀网格分桶 | 实现简单，O(V×k)复杂度 |
| 法线过滤 | dot≥0.1 | 防止背面串色，阈值宽松 |
