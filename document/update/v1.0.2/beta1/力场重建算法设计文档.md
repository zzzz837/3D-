# Force Field Reconstruction Algorithm Design - Method A and Method A+B

## 1. Problem Background

The TactileSense physical 3D mode uses Wendland C2 kernel to reconstruct force field from discrete cell pressure values onto the 3D model surface.

The current algorithm works well on complex surfaces (chair model) but shows visible **faceting artifacts** on simple surfaces (half-cylinder indenter).

### Root Cause

Heatmap rendered directly on triangle mesh faces. Simple CAD surfaces have coarse meshes, causing:
1. Per-face color averaging creates stair-step color jumps between adjacent faces
2. Insufficient vertex density prevents smooth Wendland interpolation
3. Vertex spacing larger than force field radius creates gaps

### Metric: Edge Color Std

Standard deviation of color differences across shared mesh edges. Higher = more faceting.

---

## 2. Method A: Smooth Overlay Surface

### Core Idea

Instead of rendering the heatmap on the original coarse mesh, **subdivide the mesh + Laplacian smoothing** creates a high-resolution overlay surface. Force field reconstruction runs on this dense mesh.

### Mesh Generation Strategy

| Model | Strategy | Parameters |
|------|----------|-----------|
| Indenter (.3dlp STL) | Barycentric subdiv x2 + Laplacian smooth x2 | 814 -> 13234 verts |
| Chair (chair2.stl) | Barycentric subdiv x1 + Laplacian smooth x1 | 25336 -> 103180 verts |

### Barycentric Subdivision

Each triangle -> 4 sub-triangles (connect edge midpoints), ~4x vertex growth.

### Laplacian Smoothing (Normal-Weighted)

$$v_i' = v_i + \lambda \cdot \frac{\sum_{j \in N(i)} w_j (v_j - v_i)}{\sum w_j}$$

Weight $w_j = \max(0, \vec{n}_i \cdot \vec{n}_j)$, prevents bleeding across sharp edges.

---

## 3. Method A+B: Overlay + Normal Displacement

### Core Idea

On top of Method A's dense mesh, convert force field values to **geometric displacement along normals**, creating 3D bulge effects at pressurized regions.

### Displacement Formula

$$\vec{v}' = \vec{v} + \hat{n}_v \cdot f(\vec{v}) \cdot h_{max}$$

- $h_{max}$: 4% of model diagonal
- Higher force = higher bulge

### Coverage Blending

$$color = grey + (heatmap - grey) \times \min(coverage \times 1.8, 1.0)$$

Low coverage shows grey model, high coverage shows full heatmap.

---

## 4. Wendland C2 Core Algorithm

### Kernel Function

$$\phi(r) = (1-r)^4 (4r+1), \quad r \in [0, 1]$$

- $r = 0$: $\phi = 1$ (full influence)
- $r = 1$: $\phi = 0$ (compact support boundary)
- $C^2$ continuous, no visual discontinuity

### Virtual Anchors

Each Cell generates 13 anchors (1 center + 8 outer ring + 4 middle ring), enhancing surface coverage.

### Normal Compatibility Filter

Skip anchors where $\vec{n}_{anchor} \cdot \vec{n}_{vertex} < 0.1$, preventing force bleeding through to model backside.

---

## 5. Rendering: Grey Model + Force Point Cloud Overlay

This experiment uses **hybrid rendering**:

1. **Grey model base**: Semi-transparent grey triangle mesh, always visible
2. **Force point cloud**: Colored points shown ONLY where field_value > 0.01; no-force areas show only grey model
3. **Cell markers**: Black-edged colored dots marking cell positions
4. **Colorbar**: 0 -> 1 force field value color mapping

Heatmap color band: DeepBlue(0.00) -> Blue(0.15) -> Cyan(0.30) -> Green(0.45) -> Yellow(0.55) -> Orange(0.70) -> Red(1.00)

## 6. Experiment Results

### 6.1 Indenter Model (half-cylinder.3dlp)

**Real model**: STL mesh + 31 real cell layout extracted from `.3dlp` file (ZIP format).
- Model size: 70 x 46 x 70mm
- Original mesh: 814 vertices, 1656 faces
- Cell radius: 5mm, distributed on base, sides, and half-cylinder surface
- Random pressure assignment (5 hot spots), query_radius=8mm

| Exp | Method | Vertices | FieldMax | ForceVerts | EdgeStd | Time |
|-----|--------|----------|----------|-----------|---------|------|
| V1 | Baseline (original) | 814 | 0.668 | 214 | **0.0794** | 0.03s |
| V2 | Method A (subdivided) | 13234 | 0.674 | 2833 | **0.0654** | 0.37s |
| V3 | Method A+B (bulge) | 13234 | 0.674 | 2833 | 0.0654 | 0.37s |

**Key finding**: EdgeStd decreased 17.6%, force vertices increased 13.2x (214 -> 2833).

## 7. Summary

| Dimension | Method A | Method A+B |
|-----------|----------|------------|
| Core value | Eliminate faceting, improve force coverage | Same as A + 3D bulge |
| Indenter EdgeStd improvement | 0.0794 -> 0.0654 (-17.6%) | Same as A |
| Chair EdgeStd improvement | 0.0701 -> 0.0577 (-17.7%) | Same as A |
| Indenter force vertex increase | 214 -> 2833 (13.2x) | Same as A |
| Chair force vertex increase | 9302 -> 37756 (4.1x) | Same as A |
| Compute cost | +16x vertices | Same as A + displacement negligible |
| Rendering | Grey model + force point cloud overlay, no-force areas show only grey | Same as A + bulge |

**Recommended**: Method A+B - eliminates faceting while providing 3D force visualization. Grey model base + force point cloud overlay, colored points only where force exists.
