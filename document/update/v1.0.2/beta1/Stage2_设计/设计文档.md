# Stage2 设计文档 — v1.0.2 力场重建算法替换（Method A+B）

> **本设计文档满足"零上下文可开发"标准。任何 Agent 仅凭本文档即可开始开发。**

---

## 1. 背景与目标

### 1.1 背景

将当前 `src/3D编辑器原型.html` 中预览模式的力场重建渲染管线，替换为设计文档 `力场重建算法设计文档.md` 定义的 **Method A+B**（网格细分 + 平滑 + 点云叠加 + 3D隆起位移）。

### 1.2 用户最终决策（Stage1 问题清单全部关闭）

| 决策项 | 最终方案 |
|--------|---------|
| 算法 | **Method A+B**（细分 + 平滑 + 隆起位移） |
| 渲染载体 | **灰色模型 + 力场点云叠加**（`THREE.Points`），模型仅保留灰色基底 |
| 色带 | **Jet 色带**（深蓝→蓝→青→绿→黄→橙→红） |
| 细分策略 | **自适应**（根据网格密度自动决定细分次数），支持粗/密两类网格 |
| 新增 UI | 隆起位移高度拖动条、点云点大小拖动条 |

### 1.3 目标

- 预览模式下：原始模型渲染为**灰色半透明基底**，力场以**Jet 色带着色点云**叠加显示（仅压力 > 0 的区域有点）
- 压力区域网格沿法线方向隆起，位移高度和点大小可由用户拖动条实时调节
- 自适应细分：简单 CAD 曲面（如半圆柱压头，814 顶点）自动细分 2 次，密集网格（如椅子，25K+ 顶点）自动细分 1 次
- 所有现有功能不受影响：手动压力 / 模拟压力（Wave/Uniform/Pulse）、Cell 编辑、撤销重做、模型导入导出

## 3. 总体架构

### 3.1 渲染管线变更（前 vs 后）

```
【旧管线】（将被替换）
  原始网格 geo → CSR 缓存 → Wendland 加权平均 → 顶点着色（vertexColors）
                                                      ↓
                                              暖色系色带 + 灰色混合

【新管线】（Method A+B）
  原始网格 geo
    ├─ 复制 → 灰色 Model Mesh（半透明材质，独立 THREE.Mesh）
    └─ 细分 + Laplacian 平滑 → 密集网格 geo_dense
          ├─ Wendland 加权平均 → 标量场 scalars[]
          ├─ Jet 着色 → 力场点云（THREE.Points，仅 scalars[i] > 0.01）
          └─ 法线位移 → 隆起几何（修改 geo_dense 顶点位置）
                            ↓
                      灰色模型 + 隆起几何 + 力场点云 三层叠加
```

### 3.2 场景层级结构（预览模式）

```
SCENE
└── RT (根 Group)
    ├── 灰色 Model Mesh (半透明，独立 mesh)
    │     material: MeshPhongMaterial { color:0x7f8998, transparent:true, opacity:0.5 }
    ├── 隆起 Mesh (细分后的位移几何)
    │     material: 同灰色 Model Mesh
    ├── 力场点云 (THREE.Points)
    │     material: PointsMaterial { vertexColors:true, size: pointSize }
    └── CG (Cell Group，不变)
```

## 4. SubStage 拆分

### SubStage 2.1: JS 网格细分引擎（独立，无 JS 内部依赖）

**目标**：实现网格自适应细分 + Laplacian 平滑，产出密集网格 `geo_dense`

**输入**：
- `M.geometry` — 原始模型几何
- `M` — 模型 Mesh（用于 world→local 坐标转换）

**输出**：
- `_denseGeo` — 细分+平滑后的 `THREE.BufferGeometry`（全局变量）
- `_subdivLevel` — 实际使用的细分次数（整数 0/1/2）

**实现要点**：

1. **自适应细分决策函数** `determineSubdivLevel(geo)`：
   ```
   edgeMaxMM = computeMaxEdgeMM(geo)   // 已有
   targetEdge = FIELD_R / 4            // 目标边长
   if edgeMaxMM <= targetEdge: level = 0
   else if edgeMaxMM <= targetEdge * 2: level = 1
   else: level = 2
   maxVerts = 200000
   约束 level 使 顶点数 × 4^level < maxVerts
   ```

2. **Laplacian 平滑函数** `laplacianSmoothGeometry(geo, iterations)`：
   - 输入：索引化几何（有 `index`）
   - 对每次迭代：构建邻接表 → 对每个顶点计算邻居中心 → 沿法线方向保留的分量位移
   - 法线加权：$v_i' = v_i + \lambda \cdot \frac{\sum w_j(v_j - v_i)}{\sum w_j}$，$w_j = \max(0, \vec{n}_i \cdot \vec{n}_j)$
   - $\lambda = 0.5$（与设计文档一致）
   - 最终 `geo.computeVertexNormals()`

3. **主函数** `buildDenseGeometry(geo, level)`：
   ```
   geo_dense = tessellateGeometry(geo.clone(), level, 200000)  // 复用已有
   geo_dense = laplacianSmoothGeometry(geo_dense, level)       // 新增
   return geo_dense
   ```

4. **调用时机**：在 `rebuildFieldCache` 开头（或独立调用），模型加载后首次进入预览模式时执行一次；模型不变时复用缓存

**禁止事项**：
- 不可修改原始 `M.geometry`
- 不可在非预览模式下执行细分（性能）

### SubStage 2.2: JS 力场点云与隆起渲染（依赖 SubStage 2.1）

**目标**：在密集网格上执行 Wendland 重建、生成 Jet 色带点云、实现法线位移隆起

**前置条件**：`_denseGeo` 已由 SubStage 2.1 生成

**输入**：
- `_denseGeo` — 密集网格几何
- Cells `C` + cell pressures
- `FIELD_R` — 力场半径
- `_bulgeHeight` — 隆起位移高度（全局变量，默认 4% 对角线）
- `_pointSize` — 点云点大小（全局变量，默认值见下）

**输出**：
- `_pointsMesh` — 力场点云 `THREE.Points`（添加到 RT）
- `_bulgeMesh` — 隆起位移后的网格 `THREE.Mesh`（替换旧的隆起 Mesh）
- 灰色 Model Mesh 的材质设置

**实现要点**：

1. **Jet 色带函数** `jetColorNew(t)` — 替换原 `jetColor`：
   ```
   DeepBlue(0.00)  → (0, 0, 143/255)
   Blue(0.15)      → (0, 0, 255/255)
   Cyan(0.30)      → (0, 255/255, 255/255)
   Green(0.45)     → (0, 255/255, 0)
   Yellow(0.55)    → (255/255, 255/255, 0)
   Orange(0.70)    → (255/255, 165/255, 0)
   Red(1.00)       → (255/255, 0, 0)
   段间线性插值
   ```

2. **Wendland 重建** `reconstructOnDenseGeo(denseGeo, anchors, fieldRadiusU)`：
   - 对密集网格每个顶点：查询分桶 → Wendland 加权平均 → 得到 `scalars[i]`
   - 返回 `Float32Array` 标量场 + 覆盖顶点索引数组 `coveredIndices`

3. **点云生成** `buildPointCloud(denseGeo, scalars, coveredIndices)`：
   - 从 `coveredIndices` 中筛出 `scalars[i] > 0.01` 的顶点
   - 构建 `THREE.BufferGeometry`：`position`（提取这些顶点的世界坐标）+ `color`（Jet 色带着色）
   - 创建 `THREE.Points(geo, new THREE.PointsMaterial({vertexColors:true, size:_pointSize, sizeAttenuation:true, depthWrite:true}))`

4. **法线位移** `applyBulgeDisplacement(denseGeo, scalars, bulgeHeight)`：
   - $\vec{v}' = \vec{v} + \hat{n}_v \cdot scalars[i] \cdot bulgeHeight$
   - `bulgeHeight` 默认值 = 模型对角线 × 0.04
   - 修改 `denseGeo.attributes.position`，`computeVertexNormals()` 后更新

5. **灰色模型设置** `setupGreyModel()`：
   - 复用原始 `M` mesh，设置材质：
     - `color: 0x7f8998`
     - `transparent: true, opacity: 0.5`
     - `depthWrite: true`
   - 或者创建 `M` 的浅拷贝 mesh

6. **覆盖度混合** `applyCoverageBlending(scalars, coveredCount)`：
   - $coverage = \min(coveredCount / totalVerts \times 1.8, 1.0)$
   - 用于调整点云透明度

**全局新增变量**：
```javascript
let _denseGeo = null;       // 细分后几何
let _subdivLevel = 0;       // 细分次数
let _bulgeHeight = 0;       // 隆起高度（初始 0，首次进预览时自动计算默认值）
let _pointSize = 0.08;      // 点云点大小（模型单位）
let _pointsMesh = null;     // 力场点云 THREE.Points
let _bulgeMesh = null;      // 隆起 Mesh
```

| `_pointsMesh` | `THREE.Points\|null` | `null` | 模块级 | 力场点云对象 |

### 5.2 函数签名与数据流

```
determineSubdivLevel(geo: BufferGeometry) → number (0|1|2)
  ├─ 内部调用: computeMaxEdgeMM(geo)
  └─ 约束: 最终顶点数 < 200000

laplacianSmoothGeometry(geo: BufferGeometry, iterations: number) → BufferGeometry
  ├─ 前置: geo 必须有 index
  ├─ 内部调用: buildVertexAdjacency(geo, n)
  └─ 参数: λ = 0.5, 法线加权 dot > 0

buildDenseGeometry(geo: BufferGeometry, level: number) → BufferGeometry
  ├─ 内部调用: tessellateGeometry → laplacianSmoothGeometry
  └─ 结果存入: _denseGeo, _subdivLevel

jetColorNew(t: number) → THREE.Color
  └─ 输入 t ∈ [0, 1]

reconstructOnDenseGeo(denseGeo, anchors, fieldRadiusU) → {scalars, coveredIndices}
  ├─ scalars: Float32Array (length = vertexCount)
  └─ coveredIndices: Uint32Array (scalars[i] > 0 的索引)

buildPointCloud(denseGeo, scalars, coveredIndices) → THREE.Points
  ├─ 过滤: scalars[i] > 0.01
  └─ 顶点世界坐标: localToWp(vertex)

applyBulgeDisplacement(denseGeo, scalars, bulgeHeight) → BufferGeometry (修改传入)
  └─ v' = v + normal * scalars[i] * bulgeHeight
```

### 5.3 预览模式生命周期

```
进入预览 (togglePreview ON)
  │
  ├─ 1. setupGreyModel()
  │     M.material → 灰色半透明
  │
  ├─ 2. if (!_denseGeo) buildDenseGeometry(M.geometry, determineSubdivLevel(M.geometry))
  │
  ├─ 3. _defaultBulgeMax = 模型对角线 × 0.04
  │      _bulgeHeight = bulgeSlider% × _defaultBulgeMax
  │
  ├─ 4. rebuildFieldCacheDense(cells, fieldRadiusU)  ← 改造版
  │     ├─ 构建空间分桶（复用）
  │     ├─ reconstructOnDenseGeo() → {scalars, coveredIndices}
  │     └─ scalars 缓存到 _denseScalars, _denseCoveredIndices
  │
  ├─ 5. applyBulgeDisplacement(_denseGeo, _denseScalars, _bulgeHeight)
  │     创建/更新 _bulgeMesh = new THREE.Mesh(displacedGeo, greyMaterial)
  │
  ├─ 6. buildPointCloud() → _pointsMesh
  │
  └─ 7. updateCellPreviewStyle(cellPressures)  ← 不变

退出预览 (togglePreview OFF)
  │
  ├─ 移除 _pointsMesh, _bulgeMesh（保留 _denseGeo 缓存）
  ├─ 恢复 M.material 原始设置
  └─ 恢复 Cell 原始样式
```

## 7. 验收标准（概要）

> 详细验收步骤见 `验收文档.md`

| 编号 | 验收项 | 通过标准 |
|------|--------|---------|
| A1 | 灰色模型基底 | 预览模式下模型显示为灰色半透明，非压力区域无非灰色顶点 |
| A2 | Jet 色带点云 | 力场点云颜色符合 Jet 色带顺序，仅压力 > 0.01 区域可见 |
| A3 | 法线位移隆起 | 高压力区域网格明显凸起，隆起高度随滑块实时变化 |
| A4 | 点大小滑块 | 拖动点大小滑块时点云点大小实时变化 |
| A5 | 自适应细分 | 半圆柱压头（814 顶点）自动 2 次细分，椅子（25K+ 顶点）自动 ≤1 次细分 |
| A6 | 模拟压力兼容 | Wave/Uniform/Pulse 三预设正常运行，点云和隆起随模拟实时更新 |
