## 二、Bridge 通信层

### 2.1 Bridge (Python → JS)

```python
class Bridge(QObject):
    statusMsg = Signal(str)      # → MainWindow._sl.setText()
    exportReady = Signal(str)    # → MainWindow._on_export()

    def cmd(self, name: str, data: dict = None) -> None:
        """通过 runJavaScript 调用 JS 的 window.pyCommand()"""
        payload = json.dumps(data or {}, ensure_ascii=False)
        js = f'window.pyCommand("{name}",{payload})'
        self._wv.page().runJavaScript(js)

    def handle(self, msg: str) -> None:
        """处理 JS 发来的 BRIDGE: 消息, 分派到对应信号"""
        o = json.loads(msg); e = o["e"]; d = o.get("d", {})
        if   e == "ready":        self.statusMsg.emit("引擎就绪...")
        elif e == "state":        self.statusMsg.emit(f"已落地:{landed}/{total}")
        elif e == "exportCells":  self.exportReady.emit(json.dumps(d))
        elif e == "error":        print(f"[JS Error] {d['msg']}")
        elif e == "modelLoaded":  self.statusMsg.emit(f"模型加载完成...")

    @property
    def total_channels(self) -> int:
        return max(self._total, 1)
```

### 2.2 BridgePage (console.log 拦截)

```python
class BridgePage(QWebEnginePage):
    def javaScriptConsoleMessage(self, level, msg, line, src):
        text = str(msg)
        if text.startswith("BRIDGE:"):
            self._bridge.handle(text[7:])   # 去掉 "BRIDGE:" 前缀
        elif "rror" in text:
            print(f"[JS Console] L{line}: {text}", flush=True)
```

## 三、3D引擎层 (HTML/JS)

### 3.1 初始化流程

```
HTML加载 → importmap解析 → three.module.js + addons + bvh 加载
  → T.BufferGeometry.prototype.computeBoundsTree/disposeBoundsTree 注入
  → WebGLRenderer 创建 ({canvas, antialias, preserveDrawingBuffer})
  → Scene + Camera + OrbitControls 创建
  → 环境光(强度2.2) + 方向光(强度2.6) 添加到Scene
  → RootGroup + CellContainer 创建
  → Raycaster 创建
  → 全局变量初始化 (MAX=0, C={}, M=null, ...)
  → 窗口resize处理器 → sz() 同步画布尺寸
  → renderLoop() 按需渲染循环
  → 1秒后 sendBridge('ready', ...)
```

### 3.2 渲染循环

```javascript
let _needsRender = true;
CT.addEventListener('change', () => { _needsRender = true });
['click','mousemove','wheel'].forEach(e =>
    document.addEventListener(e, () => { _needsRender = true }));

function renderLoop() {
    requestAnimationFrame(renderLoop);
    if (_needsRender || PREVIEW || dragging) {
        CT.update();          // 更新OrbitControls
        R.render(SC, CA);     // GPU渲染
        _needsRender = false;
    }
}
renderLoop();
```

- 空闲: 不渲染 (CT.update()不调用, GPU空闲)
- 操作: OrbitControls/鼠标/键盘 → `_needsRender=true` → 渲染一次
- 拖拽: `dragging=true` → 持续渲染
- 预览: `PREVIEW=true` → 持续渲染+updateHeatmap()

### 3.3 Cell 渲染函数

| 函数 | 说明 |
|------|------|
| `BC(id)` | **BuildCell**: 为单个Cell创建 Three.js Group (Mesh+Line+Sphere) |
| `addOrUpdateCell(id)` | 添加或重建Cell (先删除旧Group再创建新的) |
| `removeCellMesh(id)` | 从场景移除Cell Group |
| `RB()` | **RebuildAll**: 清空全部Cell → 遍历C重建所有 |
| `HL()` | **Highlight**: 根据F (focusId) 和 V (overlapMap) 更新Cell材质颜色 |
| `CO()` | **ComputeOverlap**: 计算所有Cell的重叠层数 (中心距离<0.45×(r1+r2)) |

### 3.4 Cell 交互函数

| 函数 | 说明 |
|------|------|
| `placeCell(hit)` | 在射线命中点放置新Cell (自动分配ID, 碰撞检测, 法向量计算) |
| `moveSelectedCell(hit)` | 移动选中Cell到命中点 (放置模式 + P键) |
| `snapShot()` | 保存当前状态快照到UNDO栈 |
| `restoreState(json)` | 从JSON快照恢复所有状态 |
| `getFreeId()` | 获取最小未使用ID |

## 四、渲染管线

### 4.1 STL导入管线

```
Python 文件对话框 → 选STL
  → base64.b64encode(read_bytes()) → Bridge.cmd("loadStl", {b64, name})
  → JS: atob(b64) → Uint8Array → STLLoader.parse()
  → BufferGeometry → computeVertexNormals()
  → computeBoundsTree() [three-mesh-bvh, O(log N) 射线检测]
  → new Mesh(geo, PhongMaterial) → RT.add(M)
  → 包围盒居中 → 自动检测单位比例
  → meshArea(M) 计算3D曲面面积
  → MAX = clamp(round(surfaceArea_mm²/400), 10, 200)
  → sendBridge('modelLoaded', {faces, size, surfaceArea, recommendedChannels})
```

### 4.2 Cell 曲面贴合 (细分顶点射线投影)

```
Cell定义 (center, normal, w, h, rot)
  ↓
PlaneGeometry(w_model, h_model, segments=10)  → 121顶点
  ↓ quaternion.setFromUnitVectors(Z轴→法向量) + rotateZ
放置在命中点, 法向对齐
  ↓
for each vertex:
  ├── 世界坐标转换 (vertex × cellMatrix × rootGroupMatrix)
  ├── 双向射线: 沿法向量正方向×cast, 反方向×cast
  ├── BVH加速交集检测
  ├── 命中约束:
  │   ├── 距离 ≤ 1.2×对角线
  │   └── 命中法向 · Cell法向 > 0.15 (同侧)
  ├── 命中: vertex → 曲面点 + 0.5mm偏移 (防Z-fighting)
  └── 未命中: 保持切平面原始位置
  ↓
computeVertexNormals() → 渲染
```

### 4.3 3D热力图预览

```
点击[3D预览] → togglePreview()
  ├── PREVIEW=true, editMode=false
  ├── 显示速度滑块 (0.5-5s)
  ├── setInterval(updateHeatmap, 60ms)
  │   └── for each Cell:
  │       value = sin(2π·t/HEAT_SPEED + id·π/N) × 0.5 + 0.5
  │       color = jetColor(value)
  │       patch.material.color = color
  └── 再点击 → PREVIEW=false → 恢复Cell原色
```

## 五、文件操作流

### 5.1 新建 (导入STL)

```
[新建] → QFileDialog (STL/OBJ/GLB)
  → b64 = base64(read_bytes())
  → bridge.cmd("loadStl", {b64, name})
  → JS: 解析 → BVH → 曲面渲染 → 自动推导MAX
  → 状态栏: "模型加载完成 | 面:xxx | 面积:xxxmm² | 建议通道:xx"
```

### 5.2 保存

```
[保存] → QFileDialog → path
  → bridge.cmd("exportCells")
  → JS: 遍历C构建cells数组 → sendBridge('exportCells', ...)
  → _on_export: 构建JSON (含surface_model.data_base64)
  → Path.write_text() → 状态栏: "已保存: xxx.json"
```

### 5.3 打开

```
[打开] → QFileDialog → path
  → json.loads(read_text())
  → version检测: "1.3" → cells映射为XY平面 (z=0)
  → version "2.0":
    bridge.cmd("loadStl", {b64: surface_model.data_base64, name, cells, total_points})
  → JS: 加载模型→BVH→恢复Cell→3D视图完整显示
```

### 5.4 另存为

```
[另存为] → 同保存逻辑, 不记住路径
```
