## 二、完整工作流程

### 2.1 流程1: 新建项目并导入模型

```
步骤1: 启动应用 (双击.exe 或 python -m src.main)
  → QWebEngineView 加载 Three.js HTML
  → 状态栏: "引擎就绪 | 点击「新建」导入STL模型"
  → 属性面板全部显示"—"

步骤2: 点击[新建] → 文件对话框
  → 过滤器: "3D模型 (*.stl *.obj *.glb *.gltf)"
  → 选择手套模型.stl

步骤3: 模型加载
  → Python: base64编码 → bridge.cmd("loadStl")
  → JS: STLLoader解析 → BVH构建 → 曲面渲染
  → 状态栏: "模型加载完成 | 面:1497123 | 面积:28123mm² | 建议通道:70"
  → 属性面板: 型号=手套模型.stl, 面数=1497123, 包围盒=X×Y×Z
  → 通道表格: 显示70行, 全部"否"
  → 篮子: 总通道数=70, 未落地=70
```

### 2.2 流程2: 放置Cell

```
方式1 — 放置模式:
  点击[放置]按钮 (或按P键) → 鼠标移到曲面上, Ctrl+点击
    → 射线检测命中点 → 计算法向量(自动朝外)
    → collisionEnabled? → 中心距离检查 →
    → 放置10×10mm正方形Cell
    → snapShot()推入UNDO栈
    → CO()计算重叠 → addOrUpdateCell()渲染
    → 篮子: 未落地-1, 下一个ID更新
    → 表格: 对应行变为"是", 填充坐标数据

方式2 — 直接Ctrl+点击:
  按住Ctrl → 点击曲面 → 放置Cell (同上)
```

### 2.3 流程3: 编辑Cell

```
选中Cell:
  点击Cell patch → F=id → HL()高亮白色
    → 属性面板刷新: ID, X/Y/Z, 边长, 面积, 旋转, 重叠
    → 表格: 对应行背景色 #0e639c44
    → 篮子: 对应ID标签高亮

调整边长:
  属性面板"边长"输入15 → 回车
    → setSquareSide(15) → C[F].w=C[F].h=15
    → CO()重新计算重叠 → addOrUpdateCell(F)重建渲染

调整旋转:
  属性面板"旋转"输入45 → 回车
    → C[F].rot=45 → addOrUpdateCell(F) → Cell绕法向量旋转

移动Cell (Ctrl+拖拽):
  Ctrl按下 → mousedown检测命中Cell → dragCellId=id, dragging=true
    → CT.enabled=false (禁用OrbitControls)
    → snapShot()保存状态
    → mousemove: 每帧射线检测曲面命中点 → 更新C[id].x/y/z/nx/ny/nz
      → addOrUpdateCell(id)实时更新渲染
    → mouseup: CO() → 最终渲染 → CT.enabled=true → msg("已移动")
    → Ctrl释放结束

删除Cell:
  选中Cell → Delete键 (或Python快捷键)
    → snapShot() → delete C[id] → removeCellMesh(id)
    → F=-1, CO(), HL()
    → 篮子: 未落地+1, ID归还
    → 表格: 对应行清空

撤销/重做:
  Ctrl+Z → UNDO.pop() → restoreState() → RB()+CO()
    → 所有UI刷新 (篮子/表格/属性/3D视图)
  Ctrl+Y → REDO.pop() → restoreState() → RB()+CO()

碰撞检测开关:
  属性面板[碰撞检测] checkbox → collisionEnabled = !collisionEnabled
    → 开启: 放置时检查中心距离 < 0.45×(r1+r2) → 阻止+警告
    → 关闭: 允许重叠放置 (视觉警示色显示)
```

### 2.4 流程4: 3D热力图预览

```
点击[3D预览] → togglePreview()
  → PREVIEW=true, editMode=false
  → 属性面板显示速度滑块 (0.5s~5s)
  → Cell按正弦波周期动画着色:
    value[i] = sin(2π·t/T + i·π/N)×0.5+0.5
    → jetColor(value) → Jet色阶 (蓝→青→绿→黄→红)
    → patch.material.color 每60ms更新
  → 拖动滑块 → HEAT_SPEED更新 → 周期变化

再点击[3D预览] → PREVIEW=false
  → clearInterval(HEAT_INTERVAL)
  → Cell恢复原色 (青/白/红 by状态)
  → 速度滑块隐藏
```

### 2.5 流程5: 保存/打开

```
保存:
  [保存] → 文件对话框 → path
  → bridge.cmd("exportCells")
  → JS构建: [{id, center_3d:{x,y,z}, normal:{x,y,z}, width_mm, height_mm, rotation_deg},...]
  → 嵌入 surface_model.data_base64
  → JSON v2.0 写入文件
  → 状态栏: "已保存: xxx.json (N个Cell)"

打开:
  [打开] → 文件对话框 → path
  → json.loads()
  → version=2.0: bridge.cmd("loadStl", {b64, name, cells, total_points})
  → JS: 加载模型 → BVH → 恢复Cell → 3D视图完整显示
  → version=1.3: cells映射XY平面(z=0) → bridge.cmd("loadJsonCells")
```
