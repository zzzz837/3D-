# 3D拟物Layout编辑器 v1.0 — 依赖与打包 (as-built)

> **版本状态**: 已构建 v1.0.0 可执行文件。本文档按实际打包结果校对。

## 一、依赖清单

### 1.1 运行时依赖

| 依赖 | 版本 | 用途 | 安装方式 |
|------|------|------|---------|
| Python | 3.10+ | 运行时解释器 | python.org |
| PySide6 | >=6.9 | Qt for Python (桌面框架, 需 QWebEngine) | `pip install PySide6` |
| numpy | >=1.26 | 数值计算 | `pip install numpy` |
| Three.js | r160 | 3D WebGL渲染引擎 | 本地bundle (lib/) |
| three-mesh-bvh | 0.7.3 | BVH空间加速 (O(log N)射线) | 本地bundle |
| PyInstaller | >=6.0 | .exe打包 | `pip install pyinstaller` |

**关于 QML**: v1.0.0 不使用 QML/QQuickWidget。UI 全部使用纯 PySide6 QWidgets (QPushButton/QLabel/QFrame)。QML 文件 (qml/) 为早期原型残留，运行时不需要。

### 1.2 本地bundle文件 (扁平化, 无CDN依赖)

```
lib/
├── three.module.js       (1,243 KB) — Three.js核心
├── index.module.js       (181 KB)   — BVH加速
├── OrbitControls.js      (29 KB)    — 相机控制
└── STLLoader.js          (10 KB)    — STL解析

总大小: ~1,463 KB
```

### 1.3 Python 标准库依赖 (无额外安装)

`json`, `os`, `sys`, `base64`, `struct`, `pathlib`, `threading`, `http.server`, `socket`, `urllib.parse`, `functools`

## 二、Three.js 本地化详情

### 2.1 importmap (3D编辑器原型.html)

```html
<script type="importmap">
{"imports":{
  "three": "./lib/three/build/three.module.js",
  "three/addons/": "./lib/three/examples/jsm/",
  "three-mesh-bvh": "./lib/three/bvh/index.module.js"
}}
</script>
```

### 2.2 ES 模块导入

```javascript
import * as T from 'three';
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';
import { STLLoader } from 'three/addons/loaders/STLLoader.js';
import { computeBoundsTree, disposeBoundsTree, acceleratedRaycast } from 'three-mesh-bvh';
```

### 2.3 兼容性说明

- Three.js 使用 ES 模块 (`<script type="module">`)
- 需要在 HTTP 服务器下加载 (不能从 `file://` 加载, 受 Chromium CORS 限制)
- 通过 Python `http.server` + `127.0.0.1:端口` 提供本地 HTTP 服务
- 全部文件本地bundle, 无需任何网络连接

## 三、PyInstaller 打包配置

### 3.1 IrregularShapedLayout.spec (as-built)

```python
a = Analysis(
    ['main.py'],                          # 入口文件 (项目根)
    datas=[
        ('3D编辑器原型.html', '.'),        # 3D引擎
        ('download.png', '.'),            # 窗口图标
        # lib/ 全部文件 (递归walk) = Three.js bundle
    ],
    hiddenimports=[
        'PySide6', 'PySide6.QtCore', 'PySide6.QtGui',
        'PySide6.QtWidgets', 'PySide6.QtWebEngineWidgets',
        'PySide6.QtWebEngineCore', 'PySide6.QtNetwork', 'numpy',
    ],
    excludes=['tkinter', 'matplotlib', 'scipy', 'IPython'],
)
exe = EXE(pyz, a.scripts, [], exclude_binaries=True,
    name='IrregularShapedLayout', icon='download.png', console=False)
coll = COLLECT(exe, a.binaries, a.datas, name='IrregularShapedLayout')
```

### 3.2 打包产物 (as-built v1.0.0)

```

├── IrregularShapedLayout.exe        (4.6 MB 启动器)
```

## 六、启动流程详解

```
1. 双击 IrregularShapedLayout.exe
       ↓
2. Python 解释器启动 (从 _internal/)
       ↓
3. QApplication 初始化 (PySide6)
       ↓
4. MainWindow.__init__()
   ├── 创建 Bridge(QObject)
   ├── _init_toolbar() — QFrame + QPushButton
   ├── _init_webview()
   │   ├── find_root() — 确定资源路径
   │   │   frozen: exe所在目录/_internal/
   │   │   dev:     src/main.py的父目录的父目录
   │   ├── start_server(root) — 本地HTTP服务器
   │   │   socket.bind(127.0.0.1, 0) → 随机端口
   │   │   ThreadPool → http.server.serve_forever
   │   ├── BridgePage → QWebEngineView.setPage()
   │   ├── QWebChannel → 注册 bridge 对象 (预留)
   │   └── load(http://127.0.0.1:PORT/3D编辑器原型.html)
   ├── _init_statusbar() — QStatusBar + QLabel
   └── _init_shortcuts() — QAction × 9
       ↓
5. QWebEngineView 加载 HTML → importmap解析
       ↓
6. Three.js ES模块加载 → 引擎初始化
       ↓
7. 1秒后 sendBridge('ready') → Python状态栏显示
       ↓
8. 窗口显示 → 用户就绪
```
