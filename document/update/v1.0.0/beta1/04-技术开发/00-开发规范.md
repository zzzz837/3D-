## 二、代码风格

### 2.1 命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| Python 模块 | `snake_case` | `model.py`, `model_importer.py` |
| Python 类 | `PascalCase` | `MainWindow`, `BridgeBackend` |
| Python 函数/方法 | `snake_case` | `_new_project()`, `load_stl()` |
| Python 私有成员 | 单下划线 | `_wv`, `_current_file` |
| Qt 信号 | `camelCase` | `statusMsg`, `exportReady` |
| JS 函数 | `camelCase` | `placeCell()`, `refreshBasket()` |
| JS 常量 | `UPPER_SNAKE` | `MAX_RECENT`, `HEAT_SPEED` |
| HTML id | `camelCase` | `propSide`, `bsTotal` |
| CSS class | `kebab-case` | `channel-table`, `auto-panel` |

### 2.2 Python 文件结构

```python
"""
模块 docstring
"""
import sys, os, json         # 标准库
from pathlib import Path

import numpy as np            # 第三方

from PySide6.QtCore import ... # Qt

from .core.model import ...   # 本项目内部
```

### 2.3 JS 代码约定

- 全局状态在 ES 模块顶层 (`let` 声明)
- Python↔JS Bridge 函数统一为 `window.pyCommand(cmd, data)`
- JS→Python 通信统一为 `sendBridge(event, data)` → `console.log('BRIDGE:'+...)`
- 渲染函数复用 `RB()` (Rebuild), `HL()` (Highlight), `CO()` (Compute Overlap)

### 2.4 行长度

- Python: 最大 100 字符
- JS (HTML inline): 无硬性限制，优先可读性，密集逻辑按功能分行
- HTML CSS: 单行无限制

**分层原则** (as-built):
- `model.py`, `geometry3d.py`, `basket.py`, `exceptions.py` 为纯 Python+numpy，无 Qt 依赖
- `model_importer.py` 依赖上述模块，无 Qt 依赖
- `main.py` 是唯一引用 PySide6 的入口文件，UI 全部使用 QWidget (QPushButton, QLabel, QFrame)
- `main.py` 不 import core/render 模块；当前版本中 3D 模型导入和逻辑均在 `3D编辑器原型.html` (JS) 中实现
- `3D编辑器原型.html` 为独立 Three.js 引擎，Python↔JS 通过 `console.log("BRIDGE:...")` + `runJavaScript()` 桥接
- QML 文件 (`qml/`) 已废弃，v1.0 运行时未使用

## 四、错误处理规范

### 4.1 自定义异常 (core/exceptions.py)

```python
class ModelImportError(Exception):
    """3D 模型导入失败。"""

class SchemaValidationError(ValueError):
    """JSON Schema 校验失败。"""

class CellBasketError(Exception):
    """Cell 篮子操作异常。"""
```

### 4.2 UI 层错误处理 (main.py)

所有异常 → `QMessageBox.warning` 或状态栏 `self._sl.setText(...)`:

```python
try:
    profile.save_json(path)
except Exception as e:
    QMessageBox.warning(self, "保存失败", str(e))
```

### 4.3 JS 错误处理 (3D编辑器原型.html)

```javascript
window.onerror = function(msg, url, line, col, err) {
    sendBridge('error', {msg: 'JS Error: ' + msg + ' line ' + line});
};
```


打包前检查:
- `3D编辑器原型.html` importmap 指向本地 `lib/three/` (无CDN)
- `IrregularShapedLayout.spec` 包含:
  - `3D编辑器原型.html`
  - `download.png` (图标)
  - `lib/three/` 全部文件 (递归)
  - `hiddenimports`: PySide6, numpy
  - `excludes`: tkinter, matplotlib, scipy, IPython
  - `icon`: download.png
