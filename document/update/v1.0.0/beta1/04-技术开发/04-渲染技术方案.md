# 3D拟物Layout编辑器 v1.0 — 渲染技术方案

> 参照 2D `04-渲染技术方案.md` 结构，全部基于 Three.js WebGL 实现。

## 一、3D渲染管线总览

```
STL文件 (ASCII/Binary)
  ↓ Python: Base64编码 → bridge.cmd("loadStl")
Three.js STLLoader.parse()
  ↓ 顶点数组 + 三角面索引 → BufferGeometry
computeVertexNormals()
  ↓ 面法线
computeBoundsTree() (three-mesh-bvh)
  ↓ BVH加速结构 (O(log N) 射线检测)
new THREE.Mesh(geometry, PhongMaterial)
  ↓ 添加到Scene
OrbitControls + 按需渲染循环
  ↓
用户交互 (旋转/缩放/平移/放置Cell/拖拽)
```

## 二、Cell曲面贴合渲染

### 2.1 细分顶点投影算法

```
Cell定义 (center, normal, width_mm, height_mm, rotation_deg)
    ↓
width_model = width_mm / unitMM      # mm → 模型坐标单位
height_model = height_mm / unitMM
    ↓
new PlaneGeometry(width_model, height_model, 10, 10)
    → 11×11 = 121 个顶点
    ↓
quaternion.setFromUnitVectors( (0,0,1), normal )
    → 将XY平面旋转到法向量方向
rotateZ(rotation_deg)
    → 绕法向量旋转
position = center + normal × 0.5mm_offset
    → 偏移防止Z-fighting
    ↓
for each vertex in PlaneGeometry:
    ├── 转换到世界坐标: worldVertex = vertex × cellMatrix × rootGroupMatrix
    ├── 双向射线检测:
    │   ├── 正方向: origin = worldVertex + normal × cast_length
    │   │          direction = -normal
    │   ├── 反方向: origin = worldVertex - normal × cast_length
    │   │          direction = +normal
    │   └── cast_length = max(width,height) × 3 或 8mm_units
    ├── Raycaster.intersectObject(modelMesh) → 命中点列表
    ├── 选取最佳命中:
    │   ├── 距离 ≤ max_jump (对角线 × 1.2 或 12mm_units)
    │   ├── 命中法向 · Cell法向 > 0.15 (同侧约束)
    │   └── (命中点 - Cell中心) · Cell法向 > -max_jump × 0.25
    ├── 命中成功: vertex = 世界坐标逆变换(命中点 + 命中法向 × 0.5mm_offset)
    └── 未命中: 使用 BVD closestPointToPoint 作为兜底
    ↓
computeVertexNormals() → 渲染就绪
```

### 2.2 关键参数

| 参数 | 值 | 依据 |
|------|-----|------|
| 细分密度 | 10×10 = 121顶点 | 平衡曲面贴合精度与性能 |
| 射线cast长度 | max(w,h)×3 或 8mm | 覆盖模型凹凸 |
| 最大跳跃距离 | max(diagonal×1.2, 12mm) | 防止跨面误投 |
| 同侧约束阈值 | 法向点积 > 0.15 | cos(81.5°) — 允许陡峭曲面 |
| Z-fighting偏移 | 0.5mm | 渲染时沿法向微偏移 |
| 单Cell三角形数 | ≤ 288 (12×12＝288面) | 200Cell时 ≤ 57,600面 |

### 2.3 Cell Group 结构

每个 Cell 在 Three.js 中的层级:

```
Group (g)
├── Mesh (ph) — PlaneGeometry 10×10 细分曲面投影
│   └── PhongMaterial { color by状态, specular:0x111, shininess:25, transparent, DoubleSide }
├── Line (ed) — 边框: 从细分几何体外边缘提取环
│   └── LineBasicMaterial { color: #ffffff 或 #ff4444 (重叠) }
└── Mesh (centerDot) — 中心点标记: SphereGeometry(r=1.2~side×0.06mm)
    └── MeshBasicMaterial { color: #4ec9b0 或 #ff4444 (重叠) }
```

## 三、BVH射线检测

### 3.1 加速结构

```
three-mesh-bvh (0.7.3)
├── 构建: computeBoundsTree() → 自顶向下SAH分割
├── 构建时机: 模型导入后立即构建 (阻塞主线程)
├── 构建成本: 150万面 ~3-5秒
├── 查询复杂度: O(log N)
├── 150万面单次命中: < 50ms
├── 注入方法:
│   T.BufferGeometry.prototype.computeBoundsTree = computeBoundsTree
│   T.BufferGeometry.prototype.disposeBoundsTree = disposeBoundsTree
│   M.raycast = acceleratedRaycast  # 替换默认raycast
```

### 3.2 射线检测使用场景

| 场景 | 函数 | 频率 | 说明 |
|------|------|------|------|
| 鼠标移动 | mousemove handler | ~15Hz | 显示曲面坐标 (30ms节流) |
| Cell放置 | placeCell() | 单次 | 命中点+法向量 |
| Cell拖拽 | mousemove (拖拽中) | ~30Hz | 实时跟踪曲面 |

## 四、Jet LUT 热力图色阶

### 4.1 颜色映射函数

```javascript
function jetColor(t) {
    // t ∈ [0, 1] → 4段分段线性插值 → 256级RGBA
    t = Math.max(0, Math.min(1, t));
    let r, g, b;

    if (t < 0.125) {
        // [0, 0.125): Blue → Cyan
        const s = t / 0.125;
        r = 0; g = 0; b = 128 + 127 * s;
    }
    else if (t < 0.375) {
        // [0.125, 0.375): Cyan → Yellow
        const s = (t - 0.125) / 0.25;
        r = 0; g = 255 * s; b = 255;
    }
    else if (t < 0.625) {
        // [0.375, 0.625): Yellow → Red
        const s = (t - 0.375) / 0.25;
        r = 255 * s; g = 255; b = 255 * (1 - s);
    }
    else if (t < 0.875) {
        // [0.625, 0.875): Red → DarkRed
        const s = (t - 0.625) / 0.25;
        r = 255; g = 255 * (1 - s); b = 0;
    }
    else {
        // [0.875, 1]: DarkRed
        const s = (t - 0.875) / 0.125;
        r = 255 * (1 - s * 0.5); g = 0; b = 0;
    }
    return new T.Color(r / 255, g / 255, b / 255);
}
```

### 4.2 正弦波驱动

```javascript
// 每个Cell独立相位偏移, 同步正弦波
const t = performance.now() / 1000;       // 已运行秒数
const value = Math.sin(
    t * Math.PI * 2 / HEAT_SPEED          // 周期 HEAT_SPEED 秒
    + cellId * Math.PI / cells.length     // 相位偏移 (总相位跨度 π)
) * 0.5 + 0.5;                           // 映射到 [0, 1]

const color = jetColor(value);
patch.material.color.copy(color);
```

### 4.3 预览着色策略

- **仅Cell patch着色**: 遍历 `O[]` 中每个 Cell Group, 修改 Mesh 的 material.color
- **无曲面顶点扩散**: 删除了之前尝试的 vertexColors 方案 (150万面遍历太慢)
- **更新频率**: `setInterval(60ms)` ≈ 16fps
- **退出恢复**: `clearInterval()` → `HL()` 恢复Cell状态驱动颜色 (青/白/红)

## 五、碰撞检测 (重叠计算)

### 5.1 算法 (CO函数)

```javascript
function CO() {
    overlapMap = {};
    const cells = Object.values(cellsData);

    for (let i = 0; i < cells.length; i++) {
        const a = cells[i];
        const rA = mm2u(Math.min(a.w, a.h) * 0.45);  // Cell等效半径
        overlapMap[a.id] = 1;  // 自身算1层

        for (let j = 0; j < cells.length; j++) {
            if (i === j) continue;
            const b = cells[j];
            const rB = mm2u(Math.min(b.w, b.h) * 0.45);
            const dx = a.x - b.x, dy = a.y - b.y, dz = a.z - b.z;
            const dist = Math.sqrt(dx*dx + dy*dy + dz*dz);

            if (dist < rA + rB) {           // 中心距离 < 等效半径和
                overlapMap[a.id]++;         // 重叠层数+1
            }
        }
    }
}
```

### 5.2 碰撞约束 (placeCell/moveSelectedCell)

```javascript
if (collisionEnabled) {
    const di = mm2u(Math.min(side, side) * 0.45);  // 45%边长 = 等效半径
    for (const c of Object.values(cellsData)) {
        const dx = p.x - c.x, dy = p.y - c.y, dz = p.z - c.z;
        const dj = mm2u(Math.min(c.w, c.h) * 0.45);
        if (Math.sqrt(dx*dx + dy*dy + dz*dz) < di + dj) {
            msg('碰撞检测: 与Cell #' + c.id + ' 过于接近', 'w');
            return;  // 阻止放置/移动
        }
    }
}
```

## 六、渲染优化策略

| 策略 | 实现细节 |
|------|---------|
| 按需渲染 | `_needsRender` 标记: 操作/拖拽/预览时渲染, 空闲时CT.update()和R.render()都不调用 |
| Cell增量更新 | `addOrUpdateCell(id)` 只删除旧Group+创建新Group, 不重建其他Cell |
| BVH缓存 | 仅在模型变更时重建 (loadStl), Cell操作不重建 |
| 预览无顶点扩散 | `updateHeatmap()` 仅修改Cell patch.color, 跳过1.5M面顶点遍历 |
| 鼠标采样节流 | mousemove handler 限制33ms间隔 (~30Hz) |
| 无阻尼 | OrbitControls.enableDamping=false 消除惯性微动 |
| Z-fighting偏移 | Cell渲染偏移0.5mm保证视觉分层 |
