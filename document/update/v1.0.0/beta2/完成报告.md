## 2. 各需求完成状态

### #0 webview 空白修复
- **代码层面**：添加 `loadFinished` 诊断 + 重试机制（限 3 次）、全局 JS 错误拦截、`BridgePage` 全量日志
- **根因定位**：**QtWebEngineProcess.exe 缺失**（PySide6 6.9.2 conda 包不完整）
- **修复**：需用户手动执行 `conda install qt6-webengine -c conda-forge`

### #1 新建项目 Dialog ✓
- 4 个核心字段：项目名称、传感器通道数（≥1 无上限）、模型文件、单位比例
- 通道数无上限（`QSpinBox.setRange(1, 999999)`）
- 不包含设备类型/描述（按 Q4 否决）

### #2 模型渲染修复 ✓
- bbox 计算前先清理 Cell（避免旧 Cell 影响居中）
- `RT.position.set()` 替代 `RT.position.sub()`（避免累积偏移）
- bbox 从 `M` 计算（不含 Cell Group）

### #6 多格式支持 ✓
- JS 端：STL/OBJ/GLB/GLTF 四个 Loader，`loadStl` 改为通用函数
- Python 端：`stp_converter.py`（pythonocc-core）
- `_new_project` 中自动识别格式并路由

### #3 ZIP 包保存/打开 ✓
- `.3dlp` 格式 = `project.json` + 原始模型文件
- 向后兼容旧版 `.json`（含 `data_base64`）

### 启动测试 — 阻塞

**原因**：`QtWebEngineProcess.exe` 缺失，`QWebEngineView` 无法加载任何页面。

**证据**：
```
[init] find_root() = D:\workshop\3D-
[init] html_path = D:\workshop\3D-\src\3D编辑器原型.html
[init] HTTP port = 54609
[init] loading URL = http://127.0.0.1:54609/src/3D%E7%BC%96%E8%BE%91%E5%99%A8%E5%8E%9F%E5%9E%8B.html
[init] WebEngine load FAILED (attempt 1/3)
```

附加验证：`setHtml('<h1>Hello</h1>')` 也返回 `loadFinished=false`，确认不是 HTML 内容问题。

**修复命令**（需用户手动执行）：
```powershell
conda install qt6-webengine -c conda-forge
```

安装后预期：终端显示 `[init] WebEngine load succeeded`，webview 完整渲染 HTML 界面。
