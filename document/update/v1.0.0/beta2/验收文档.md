## 4. 验收项

### A1. 应用启动 — webview 不空白

- **目的**：验证 #0 修复生效，webview 不再空白
- **前置条件**：无
- **操作步骤**：
  1. 在仓库根目录执行 `python src/main.py`
  2. 等待窗口完全加载
- **期望结果**：
  - Python 工具栏可见（顶部一行按钮）
  - webview 区域显示 HTML 完整界面：左侧 Cell 篮子、中央 3D 画布（深色背景）、右侧属性面板、下侧通道表格、底部蓝色状态栏
  - 状态栏显示"就绪"或"引擎就绪"
- **通过标准**：上述所有 UI 区域均可见且非空白
- **失败标准**：webview 区域全白/全黑/无任何 HTML 元素
- **证据要求**：截图（窗口全貌）+ 终端输出（无报错）

### A2. 应用启动 — 终端无报错

- **目的**：验证 Python/JS 层面无异常
- **前置条件**：同 A1
- **操作步骤**：启动时观察终端输出
- **期望结果**：无 `[JS Error]`、无 Python traceback、无 `QWebEngine` 相关警告
- **通过标准**：终端干净，或仅有 info 级别输出
- **失败标准**：出现 `[JS Error]` 或 Python 异常
- **证据要求**：终端输出文本（最后 30 行）

### A3. 新建项目 — Dialog 交互

- **目的**：验证 #1 Dialog 正确弹出和参数收集
- **前置条件**：应用已启动（A1 通过）
- **操作步骤**：
  1. 点击 Python 工具栏"新建"按钮
  2. 观察弹出 Dialog
  3. 检查 Dialog 包含：项目名称输入框、通道数输入框、模型文件（带浏览按钮）、单位比例输入框
  4. 不填任何内容直接点"确定"
  5. 填写项目名称"测试项目"、通道数 50、点击浏览选择 `src/手套模型.stl`、单位比例保持默认
  6. 点"确定"
- **期望结果**：
  - 步骤 4：弹出"请输入项目名称"警告
  - 步骤 5-6：Dialog 关闭，模型加载到 3D 画布
  - 状态栏显示类似"项目: 测试项目 | 模型: 手套模型.stl | 通道: 50"
- **通过标准**：Dialog 4 个字段齐全，空名称拦截，STL 选择后正常关闭
- **失败标准**：Dialog 不弹出 / 字段缺失 / 点确定后崩溃 / 模型未加载
- **证据要求**：Dialog 截图 + 加载后的窗口截图

### A4. 模型渲染

- **目的**：验证 #2 模型在 3D 画布正确渲染
- **前置条件**：A3 通过（模型已加载）
- **操作步骤**：
  1. 观察 3D 画布区域
  2. 鼠标旋转/缩放/平移视角
  3. 检查模型是否可见、位置是否居中
  4. 鼠标悬停模型表面，检查左下角"鼠标曲面"坐标是否变化
- **期望结果**：
  - 3D 画布中可见手套模型（灰色半透明）
  - 模型居中，可用鼠标旋转缩放
  - 鼠标悬停时左下角状态栏实时显示曲面坐标
- **通过标准**：模型可见且可交互
- **失败标准**：3D 画布全黑 / 模型不可见 / 交互无响应
- **证据要求**：模型渲染截图 + 包含曲面坐标的状态栏特写

### A5. Cell 放置

- **目的**：验证 Cell 可贴合模型曲面
- **前置条件**：A4 通过
- **操作步骤**：
  1. 确保编辑模式（状态栏 Ctrl:—）
  2. Ctrl+Click 或点击"放置模式"后在模型表面放置 2-3 个 Cell
  3. 观察 Cell 是否正确贴合曲面
  4. 点击 Cell 选中，检查右侧属性面板显示坐标/法线/半径
- **期望结果**：
  - Cell 贴合在模型表面（法线方向正确）
  - 选中后属性面板显示坐标、法线、半径等信息
  - 左侧篮子"已落地"计数增加
- **通过标准**：Cell 可见且贴合曲面
- **失败标准**：Cell 无法放置 / 飘离曲面 / 属性面板空白
- **证据要求**：Cell 放置后截图 + 属性面板特写

### A6. 保存 .3dlp 包

- **目的**：验证 #3 ZIP 包导出
- **前置条件**：A5 通过（至少 2 个 Cell 已放置）
- **操作步骤**：
  1. 点击"保存"
  2. 选择保存类型 `3D Layout Package (*.3dlp)`，文件名为 `test.3dlp`
  3. 保存
  4. 用解压工具（7-Zip/WinRAR）打开 `test.3dlp`，检查内部文件
- **期望结果**：
  - `test.3dlp` 生成成功
  - 解压后包含 `project.json` + 模型 STL 文件
  - `project.json` 包含 `project_name` / `cells` / `unit_mm` 等字段
  - `cells` 数组长度 = 之前放置的 Cell 数量
- **通过标准**：ZIP 可解压，内容正确
- **失败标准**：保存失败报错 / ZIP 损坏 / cells 为空 / 模型文件缺失
- **证据要求**：`project.json` 前 30 行内容 + ZIP 文件结构截图

### A7. 打开 .3dlp 包 — 数据闭环

- **目的**：验证保存的数据可完整还原
- **前置条件**：A6 通过（`test.3dlp` 存在）
- **操作步骤**：
  1. 关闭当前窗口（或点新建清空状态）
  2. 点击"打开"
  3. 选择 `test.3dlp`
  4. 检查模型是否加载
  5. 检查 Cell 是否恢复到保存时的位置
  6. 选中一个 Cell，对比属性面板的坐标/半径与保存前一致
- **期望结果**：
  - 模型正确加载
  - 所有 Cell 恢复，位置/大小与保存前一致
  - 通道数、单位比例与保存前一致
- **通过标准**：Cell 数量、位置、大小完全一致（允许浮点精度误差 <0.05mm）
- **失败标准**：模型未加载 / Cell 数量不对 / Cell 位置明显偏移
- **证据要求**：打开后截图 + 选中最上方 Cell 的属性面板数值

### A8. STEP 格式支持

- **目的**：验证多格式加载（STP/STEP）
- **前置条件**：conda 环境 `3d-editor` 已配置，有可用 STP 文件（如仓库中的 `半圆柱压头φ12_.stp`）
- **操作步骤**：
  1. 点击"新建"
  2. 在模型文件浏览中选择 STP/STEP 文件（如 `半圆柱压头φ12_.stp`）
  3. 确定
- **期望结果**：
  - Python 端自动转换为 STL → JS 端加载
  - 模型在 3D 画布中正确渲染
- **通过标准**：STP 模型可见且可交互
- **失败标准**：转换失败 / 模型不显示 / 崩溃
- **证据要求**：终端转换日志 + 模型渲染截图

### A9. 回归冒烟 — 历史功能

- **目的**：确认本次改动未破坏已有功能
- **前置条件**：A5 通过
- **操作步骤**：
  1. 点击"线框"按钮 → 检查线框显示/关闭
  2. 点击"3D预览" → 检查热力图动画
  3. 点击"截图PNG" → 检查 PNG 文件生成
  4. 点击"撤销" → 检查最后放置的 Cell 被移除
  5. 点击"重做" → 检查 Cell 恢复
  6. 点击"重置" → 检查视角恢复默认
- **期望结果**：所有按钮功能正常
- **通过标准**：各功能响应正确，无崩溃
- **失败标准**：任一按钮无响应或崩溃
- **证据要求**：每个功能执行后的状态确认（截图或文字描述）
