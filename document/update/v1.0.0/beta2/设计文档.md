# beta2 设计文档

> **版本**: v1.0.0-beta2 | **架构**: PyQt5 + QWebEngineView + Three.js r160
> **日期**: 2026-07-08

---

## 1. 架构概览

```
┌─────────────────────────────────────────────┐
│ PyQt5 MainWindow                            │
│  ├── QFrame (Python 工具栏: 新建/打开/保存)  │
│  └── QWebEngineView                         │
│       └── http://127.0.0.1:{port}/src/      │
│            └── 3D编辑器原型.html             │
│                 ├── Three.js WebGLRenderer   │
│                 ├── OrbitControls            │
│                 ├── BVH ray casting          │
│                 └── Python↔JS Bridge         │
└─────────────────────────────────────────────┘
```

**数据流**：Python 读模型→写 `src/_model_cache/`→JS 通过 `fetch()` HTTP 下载→BVH 构建→渲染。

## 2. 接口契约

### Python → JS (Bridge.cmd)

| 命令 | payload | 说明 |
|------|---------|------|
| `loadStl` | `{url, name, format, total_points, cells?}` | HTTP URL 加载模型 |
| `exportCells` | `{}` | 导出当前 Cell |
| `undo/redo` | `{}` | 撤销/重做 |
| `wire/reset/togglePlace/toggleEdit/togglePreview` | `{}` | 视图控制 |
| `setUnit` | `{unit}` | 设单位比例 |
| `setRadius/setLabel/setRot` | `{...}` | Cell 属性 |
| `escape` | `{}` | 取消选中 |
| `screenshot` | `{path}` | 截图 |

### JS → Python (Bridge.handle)

| 事件 | payload | 说明 |
|------|---------|------|
| `ready` | `{max, radius, unit}` | 引擎就绪 |
| `state` | `{landed, max, overlap}` | 状态更新 |
| `exportCells` | `{cells, total_points}` | Cell 导出 |
| `modelLoaded` | `{faces, size, surfaceArea}` | 模型加载完成 |
| `error` | `{msg}` | 异常上报 |

## 3. 关键设计决策

### 3.1 PyQt5 (非 PySide6)
PySide6 Qt6 WebEngine 在本机 GPU 环境下无法创建 WebGL 上下文。PyQt5 QtWebEngine 5.15.7 与 Intel UHD Graphics D3D11/ANGLE 完美兼容。

### 3.2 HTTP URL 模型传输 (非 base64)
75MB STL base64 编码后约 100MB，通过 `runJavaScript()` 传送致 WebEngine 崩溃。改为写入 `src/_model_cache/`，JS 通过 `fetch(url)` 异步下载。

### 3.3 直接相对路径 (非 importmap)
Chromium 83 (Qt5) 不支持 `<script type="importmap">`。所有 JS 模块通过相对路径导入（修改 8 个 vendored 文件中的 `from 'three'`→`from '../../../build/three.module.js'`）。

### 3.4 WebGL try-catch
WebGL 初始化包裹在 try-catch 中，失败时只隐藏 canvas 显示提示，不中断脚本执行（避免菜单事件未绑定）。

## 4. 项目包格式 (.3dlp)

```
project.3dlp (ZIP/DEFLATED)
├── project.json       # 元数据 + cells（不含 base64）
└── {model_name}       # 原始模型文件
```

`project.json`：`version`, `project_name`, `created_at`, `total_points`, `unit_mm`, `model_file`, `cells[]`
