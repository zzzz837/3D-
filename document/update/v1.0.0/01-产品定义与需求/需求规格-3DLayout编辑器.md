## 1. 功能需求总览

3D 拟物 Layout 编辑器是一个**完全独立的桌面应用程序**，用于在任意 3D 曲面模型（如手套、鞋垫、护具等）上创建和编辑触觉传感器 Cell 的布局配置。用户完成以下固定工作流后，导出 `.json` 文件供主软件加载使用：

```
启动应用 → 导入3D曲面模型 → 在曲面上放置Cell → 调整Cell位置/大小 → 3D热力图预览 → 保存导出
```

编辑器**不连接设备**、不接收传感器数据。预览模块使用内置正弦波生成器模拟数据，供用户验证布局的视觉效果。

**架构**：Python (PySide6) 提供桌面容器和原生文件对话框，3D 渲染与 Cell 交互由内嵌 Three.js HTML 引擎处理。Python 和 JS 之间通过 QWebChannel Bridge（Signal/Slot 机制）双向通信。

**与 2D 编辑器 v1.3 的关系**：
- 3D 编辑器是独立产品，非 2D 的升级版本或替代品
- 可打开 2D v1.3 JSON 文件，将 2D Cell 自动映射到 XY 参考平面（z=0）
- 3D 编辑器的数据模型和 JSON Schema（v2.0）兼容 2D 工具链

## 2. 核心功能需求 (Functional Requirements)

### FR-01: 配置管理 (Configuration Management)

#### FR-01.1: 新建配置
用户通过对话框创建 3D 布局配置文件。

**输入项**：
| 字段 | 类型 | 约束 | 默认值 |
|------|------|------|--------|
| 设备型号 (device_model) | 字符串 | 必填，1-64 字符 | 空 |
| 显示名称 (display_name) | 字符串 | 可选，≤128 字符 | 空 |
| 通道数量 (total_points) | 整数 | 必填，1-200，用户手工输入，不从3D模型自动推断 | 128 |
| 3D 曲面模型 (surface_model) | 文件路径 | 必填 | 通过文件对话框选择 |

**Surface Model 支持的导入格式**：
| 格式 | 扩展名 | 说明 |
|------|--------|------|
| STL (ASCIl/Binary) | `.stl` | 行业标准三角面片格式 |
| Wavefront OBJ | `.obj` | 含材质和法线信息 |
| GLTF/GLB | `.gltf` `.glb` | 现代 3D 传输格式 |

**校验规则**：
- 任一必填字段为空或数值非法时，"创建"按钮置灰
- Surface model 文件必须能够成功解析为有效三角面片集合
- 模型面数 ≤ 500,000（超出则提示简化）

**结果**：生成空白 `DeviceLayoutProfile3D`，Cell 篮子满载（全部 channel ID 处于未落地状态），3D 视口显示导入的曲面模型。确认后立即将 JSON 文件写入指定路径。

**通道数来源说明**：`total_points` 表示传感器硬件通道数量，必须由用户或配置文件明确给出；3D 曲面模型只提供可放置曲面与几何尺寸，不能自动推断传感器通道数。原型页面可在未超过已落地 ID 的前提下手工修改总通道数。

#### FR-01.2: 打开配置
- 通过文件对话框选择 `.json` 布局配置文件。
- 自动识别 Schema 版本：
  - `"2.0"` → 按 3D 模式加载（曲面模型 + 3D Cell）
  - `"1.3"` → 按 2D 兼容模式加载（Cell z=0 映射到 XY 参考平面，见 FR-10）
- 校验通过后恢复全部状态：曲面模型、Cell 列表、篮子状态、相机位置。
- 校验失败时弹出错误提示，列出具体问题。

#### FR-01.3: 保存配置
- 覆盖当前文件路径写入 JSON（Schema v2.0 或 v1.3 兼容格式）。
- 若当前文件路径为空（新建后首次保存），自动触发"另存为"流程。
- **保存前自动执行曲面覆盖缺口检测**（FR-19）：若检测到缺口区域，在3D视口顶部显示红色警告栏并标记缺口位置，但不阻止保存。
- 保存成功后清除 `isDirty` 标记。

#### FR-01.4: 另存为
- 通过文件对话框选择新路径保存 JSON。
- 默认目录为 `layout_profiles/`（相对于可执行文件目录）。
- 保存成功后更新当前文件路径引用。

#### FR-01.5: 未保存提示
以下操作前，若 `isDirty = true`，弹出确认对话框：
- 新建配置
- 打开配置
- 关闭窗口 / 退出应用

对话框选项：保存 / 不保存 / 取消。选择"取消"时中止当前操作。

#### FR-01.6: 最近文件
"文件"菜单底部显示最近打开的配置文件列表（最多 5 项），点击直接打开对应文件。最近文件列表在应用关闭时持久化到用户设置。

#### FR-01.7: 替换曲面模型
工具栏 `[替换模型]` 按钮或"工具"菜单触发，弹出文件对话框选择新的 3D 模型文件替换当前曲面。替换后保留所有已放置 Cell 的位置（仅当 Cell 投影仍在曲面范围内时保留，否则标记为"待重放置"）。

### FR-02: 3D 曲面模型导入与管理 (Surface Model Import)

#### FR-02.1: 模型导入管道
```
文件选择 → 格式检测（扩展名/魔数） → 解析器选择 → 三角网格提取 → 坐标系验证 → 法线计算/修复 → 渲染上传
```

#### FR-02.2: 各格式解析要求

| 格式 | 解析范围 | 不支持特性处理 |
|------|----------|----------------|
| STL ASCII | 顶点坐标 + 面法线 | — |
| STL Binary | 80字节头 + 4字节面数 + 逐面读取 | — |
| OBJ | v顶/点, vn法线, f面, g组 | mtl材质、纹理坐标（忽略） |
| GLTF/GLB | mesh primitives (TRIANGLES only), POSITION, NORMAL | 骨骼、动画、材质纹理、PBR属性（忽略） |

#### FR-02.3: 模型预处理
导入完成后自动执行：
- **法线计算**：缺失面法线的三角面按右手定则自动计算
- **法线统一**：所有面法线翻转到一致朝向（基于连通分量分析，向外为正）
- **连通性检查**：识别闭合/开放曲面、孤立顶点、非流形边，记录警告
- **单位确认**：STL 本身不存储物理单位，导入时必须明确 `mm_per_model_unit`（每 1 个模型坐标单位对应多少 mm），默认按 1 模型单位 = 1mm 预填
- **单位换算**：所有 Cell 宽度、长度、面积、间距、偏移量均以真实 mm 存储；渲染和射线计算时统一换算为模型坐标单位：`model_units = mm / mm_per_model_unit`
- **尺寸校验**：导入后显示模型原始包围盒和换算后的物理包围盒。若换算后任一维度 < 40mm 或 > 1000mm，必须提示用户确认单位（mm/cm/m/inch/自定义比例）

#### FR-02.4: 模型验证
导入后执行以下检查，任一不通过则阻止加载并给出明确的修复建议：
- 三角面数 ≥ 1（非空网格）
- 所有面为三角形（非四边形或多边形混合）
- 顶点坐标非 NaN/Inf

#### FR-02.5: 模型显示
3D 视口默认显示以下视觉元素（Three.js 渲染）：
- 曲面网格：半透明灰色材质（`#808080`，opacity 0.3），线框模式可选关闭
- 曲面光照：默认环境光 + 单方向光源，支持 Phong 着色
- 曲面轮廓边：高对比度白色线条（opacity 0.6）

#### FR-02.6: 大模型交互性能约束
- 对超过 100,000 三角面的 STL/OBJ/GLTF，导入后必须构建 BVH 或等价空间加速结构，用于鼠标拾取、Cell 顶点投影、缺口检测与自动填充采样。
- 不允许在每次放置 Cell 时对全模型做无加速逐三角面射线遍历；150 万三角面级别模型单次放置响应目标 ≤ 300ms。
- Cell 曲面面积、贴合后的顶点几何、重叠状态应缓存；只有该 Cell 的位置、尺寸、旋转或单位比例变化时才重新计算。
- 放置单个 Cell 时优先增量创建/更新该 Cell，不得无条件重建全部 Cell 的曲面贴合网格。
- 视口顶部应实时显示鼠标曲面坐标与相机缩放/距离比例，便于用户判断当前操作尺度。

### FR-03: 3D 视口导航 (3D Viewport Navigation)

#### FR-03.1: 轨道控制 (Orbit)
- **左键拖拽**：围绕视口中心点旋转相机（Orbit，Three.js OrbitControls）
- **滚轮**：缩放（dolly），以鼠标指向的曲面点为参考中心
- **中键拖拽**：平移相机（pan）
- **右键拖拽**：旋转相机（备选，与左键等价）

#### FR-03.2: 预设视角
"视图"菜单提供快速切换预设视角（带平滑过渡动画）：
| 视角 | 说明 |
|------|------|
| 顶视图 (Top) | 相机沿 +Z 俯视，XY 平面对齐屏幕 |
| 底视图 (Bottom) | 相机沿 -Z 仰视 |
| 前视图 (Front) | 相机沿 -Y 正视 |
| 后视图 (Back) | 相机沿 +Y 正视 |
| 左视图 (Left) | 相机沿 +X 侧视 |
| 右视图 (Right) | 相机沿 -X 侧视 |
| 重置视角 (Reset) | 恢复默认相机位置 |

#### FR-03.3: 视角重置
- 快捷键 `Ctrl+0`：重置相机到默认位置（俯仰 30°，方位角 -45°，自动适应模型包围盒）
- 双击"重置视角"菜单项效果同上

#### FR-03.4: 坐标轴指示器
3D 视口左下角显示 RGB 三色坐标轴指示器（X=红, Y=绿, Z=蓝），随相机旋转同步更新，帮助用户理解空间朝向。

#### FR-03.5: 选中聚焦
当通过其他面板（Cell 篮子、通道表格）选中某个 Cell 时，相机自动平滑过渡使该 Cell 居中显示在视口中心。

### FR-04: Cell 管理 (Cell Management)

#### FR-04.1: 拖拽放置
用户从 Cell 篮子的 `[← 拖出下一个]` 控件拖拽到 3D 视口曲面模型上：

- 拖拽过程中：鼠标光标处显示半透明 Cell 幽灵（正方形 patch，与曲面法向对齐）
- **射线检测**：从鼠标位置发射射线与曲面三角面求交
- 释放鼠标时，以交点为中心，曲面法向量为朝向，在曲面上创建 Cell
- 仅在命中曲面时创建 Cell；未命中曲面则取消拖拽
- 支持自定义拖拽方案（跨坐标空间精确定位，非 Qt 内置 Drag/Drop）

#### FR-04.2: 默认形状
新建 Cell 默认形状为**正方形 patch**：
- 边长：当前原型采用固定正方形 Cell，`width_mm == height_mm == side_mm`。默认参考 2D 编辑器的 `10mm × 10mm`，但 3D 模型物理尺寸差异较大时应按模型长边自动给出建议值：`side_mm = clamp(model_max_dim_mm * 0.02, 10, 28)`。该建议值仅作为新建/自动填充默认值；用户可在属性面板手工输入任意大于 0 的真实物理边长，不设置上限。
- 初始朝向：以曲面交点处的局部 U/V 方向对齐（默认 U 方向 = 曲面切平面最大曲率方向）
- Cell 由 4 个曲面顶点定义，顶点间沿曲面测地线连接
- Cell 法向量统一指向曲面外侧（自动检测并翻转向内法线）
- 对于极端模型（包围盒最大维度 < 40mm 或 > 1000mm），导入时弹出"单位确认"对话框提示用户确认缩放比例

#### FR-04.3: Cell 尺寸调整
- **角点拖拽**：拖拽 Cell 4 个角点之一，沿曲面滑动，改变 patch 形状（保持正方形约束）
- **等比缩放**：按住 Shift + 拖拽角点，保持正方形比例（原型尚未实现，Python 实现保留此接口）
- **边长调整**：属性面板单一 `边长` 字段输入 `side_mm` 数值（默认由模型尺寸建议值确定，可手工输入 >0 的任意值）
- 尺寸变化后，Cell 细分顶点在曲面上重新投影贴合

#### FR-04.4: 拖拽幽灵
拖拽过程中，3D 视口跟随鼠标显示幽灵预览：
- 正方形半透明 patch（opacity 0.5）
- 贴合曲面法向显示
- patch 中心显示即将落地的 channel ID 标签（如 `#4`）
- 幽灵颜色：蓝色 `#0078FF` 半透明

#### FR-04.5: Cell 选中
以下方式可选中 Cell（进入 Focus 状态）：
- 鼠标左键点击 3D 视口中的 Cell patch 区域
- 点击篮子中已落地 ID 标签
- 点击通道表格对应行

Focus 状态视觉变化：
- Cell patch 边缘显示**高亮虚线边框**（白色，`#FFFFFF`，线宽 2.5px，dash 模式 [6,3]）
- Cell 4 个顶点显示球形控制手柄（直径 3mm，黄色 `#FFD700`）
- Cell 中心显示法向量箭头指示器（黄色，长度 5mm）
- 属性面板刷新显示该 Cell 信息
- 通道表格对应行高亮

取消 Focus：按 `Escape` 或点击 3D 视口空白区域。

#### FR-04.6: Cell 曲面移动
Focus 状态下，鼠标按下并拖拽 Cell patch 内部区域：
- Cell 沿曲面实时滑动（每帧重新投影到曲面）
- 拖拽时发射 `cell_moved` 信号
- 鼠标释放时推入 UndoStack（`MoveCell3DCommand`）
- 拖拽过程中 Cell 始终保持与曲面贴合

#### FR-04.7: Cell 旋转
Focus 状态下，Cell 边缘显示**两个旋转手柄**（绿色弧形箭头，直径 5mm）：
- **面内旋转手柄**（沿曲面法向量旋转）：拖拽绕 Cell 中心法向量旋转
- **倾斜手柄**（沿曲面切平面旋转）：调整 Cell 在曲面上的朝向角度
- 旋转增量：1°
- 释放时推入 UndoStack（`RotateCell3DCommand`）

#### FR-04.8: Cell 删除
以下方式触发删除：
- 右键菜单选择"删除此 Cell"
- Focus 状态下按 `Delete` 键

删除后：
- 从 3D 视口移除该 Cell 的所有图形元素
- 该 Cell 的 channel ID 归还到篮子未落地集合
- 通道表格对应行清空
- 操作推入 UndoStack（`UnlandCell3DCommand`）

#### FR-04.9: 批量选择
- `Ctrl+A`：全选所有已落地 Cell
- `Ctrl+Click`：多选 Cell（追加到选中集合）
- 多选状态下，删除操作同时删除所有选中 Cell

#### FR-04.10: Cell 放置约束
- Cell 中心必须投射到曲面有效区域（距离最近三角面 < 模型包围盒对角线的 2%）
- 连续两个 Cell 的中心预警距离采用宽松策略，避免“稍微挨着就标红”：仅当中心距 `< 0.45 × (min(width_A,height_A)+min(width_B,height_B))` 时判为疑似重叠；真实重叠检测应以 FR-18 的栅格/SATP patch 相交为准。自动填充仍可使用 `minGap` 保持额外间距。
- 曲率过于陡峭的区域（局部法向量与全局 Z 轴夹角 > 85°）标记为警告，不阻止放置但给出视觉提示
- 属性面板可关闭碰撞检测（CheckBox），关闭后仅保留曲面内检查

#### FR-04.11: Cell 曲面贴合渲染 (Surface Conformity Rendering)

Cell 必须在 3D 视口中按真实传感器尺寸**贴合 3D 曲面表面积**，用于布置压力传感器点位，不能以平面穿透曲面。技术要求：

- **真实尺寸换算**：Cell 的 `width_mm` / `height_mm` 是真实物理尺寸，渲染尺寸必须使用 `width_mm / mm_per_model_unit` 和 `height_mm / mm_per_model_unit`
- **网格细分**：Cell 渲染网格必须细分为 N×N 个子三角形（默认 12×12，可按性能降级到 8×8），不能仅使用 2 个三角面的平面 Plane
- **双向顶点投影**：每个细分顶点必须沿 Cell 法向量正反两个方向射线检测曲面，选取距离最近命中点，避免因局部法线方向或凹凸区域导致投影失败
- **曲面面积近似**：Cell 显示面积应优先根据贴合后细分三角形面积求和，不能只用平面 `width × height` 作为曲面面积
- **表面偏移**：渲染时将 Cell 沿曲面法向量向外偏移 0.3mm~0.8mm（换算为模型单位），仅用于防止 Z-fighting，不得改变保存的物理位置
- **幽灵预览**：拖拽放置时的幽灵 Cell 同样需要细分贴合曲面
- **性能约束**：单个 Cell 的细分三角形数建议 ≤ 288（对应 12×12 细分），200 个 Cell 时总面数 ≤ 57,600

#### FR-04.12: 复杂曲面贴合与自动布局

3D 编辑器面向手套、护具等复杂曲面，Cell 放置不应因为局部曲率高而被阻止。渲染层必须尽力将 Cell 贴到曲面上，而不是把曲面复杂度作为错误处理。

**工程目标**：本编辑器用于在建模后的 3D 物体表面布置表面传感器。Cell 是贴附在 3D 表面上的柔性传感器片，不是垂直插入模型的平面块，也不是脱离表面的立体几何体。

**形状约束**：工程应用中的传感器 Cell 具有固定物理尺寸。当前原型统一采用正方形传感器片，宽高相等，渲染为贴在曲面命中点法向上的正方形平面。规则外框和中心标记确保重心始终位于命中点、不会因投影算法产生偏移。

**贴合规则（当前原型实现）**：
- 算法：Cell 细分顶点射线投影。在命中点沿曲面法向放置细分正方形（默认 10×10 细分），对每个顶点沿 Cell 法向正反两个方向各发一条射线（cast=Cell对角线×5），选取距离最近的命中点作为曲面贴合点，再沿局部表面法向外偏 0.5mm 防 Z-fighting。
- 同侧约束：高曲率手指区域禁止顶点投影跨到手指对面。候选命中点必须满足距离原顶点不超过约 `1.2×Cell对角线`，且命中法向与 Cell 中心法向同向；若不满足则保留局部切平面位置或使用同侧最近点兜底。
- 射线使用 BVH 加速（`three-mesh-bvh`），保证 150 万三角面手套模型下单次投影 < 50ms。
- 若某顶点双向射线均未命中曲面，该顶点保持切平面原始位置不变（不阻止放置）。
- 放置时 Cell 中心必须位于射线命中的曲面点，Cell 法向量采用命中点曲面法线并自动朝外翻转。
- Cell 的 `width_mm == height_mm == side_mm`（正方形），由属性面板单一 `边长` 字段控制，修改时长宽同步。
- 贴合只改变细分渲染网格的顶点位置；数据模型仍保存中心、法线、边长、旋转。
- Cell 面片、边框、中心点必须作为一个整体显示：边框从贴合后的细分网格外边缘提取，中心点固定在 Cell 命中重心并沿同一法向微偏移，三者共享同一个 Cell ID 和选中/重叠状态，避免出现“重心点、边框、面片分离”的误读。
- 颜色：统一青色 `#4ec9b0`，选中变白，重叠变红/橙红。

**总通道数与布局数量**：
- `total_points` 表示硬件总通道数，`cells` 可为稀疏布局；缺失 ID 可在导出/加载时以 `width_mm=0` 的 dummy Cell 补齐，2D 工具链已有相同策略。
- 当前 HTML 原型已移除“均匀布局”按钮，避免在复杂 3D 曲面上生成不可控的自动铺设结果。
- 当前保留两种布置方式：手动放置/重定位，以及“自动填充”面板在平坦区域生成候选 Cell。复杂曲面区域以人工布置为主。
- 保存时应保证已落地 Cell 的 ID 与通道下标一致；未落地通道保持在篮子中，后续导出/加载可按 dummy Cell 策略补齐。
- 默认 Cell 尺寸应避免视觉面积过大：建议 `recommended_cell_mm = clamp(model_max_dim_mm * 0.02, 10, 28)`，用户可手动调整到真实传感器尺寸。
- 原型中已集成 Undo/Redo（深度 50 步，支持放置/删除/移动/边长修改/单位修改/自动填充批量操作）。撤销快捷键 `Ctrl+Z`，重做 `Ctrl+Y`。
- 已放置 Cell 支持重定位：选中某个 Cell 后，用户点击新的曲面位置即可将该 Cell 移动到新位置，保留原 ID、宽高和旋转角。
- 交互性能要求：单个 Cell 放置或重定位目标响应 ≤ 150ms。原型可降低细分数、使用 BVH 最近点/射线加速与缓存，避免每次点击对全量三角面排序。

### FR-11: 文件格式 (File Format)

#### FR-11.1: JSON Schema v2.0
配置文件使用 JSON 格式，Schema 版本 `"2.0"`。

#### FR-11.2: 文件扩展名
文件扩展名为 `.json`，文件命名建议：`{device_model}_3d.json`。

#### FR-11.3: Schema 结构

```jsonc
{
  "version": "2.0",
  "device_model": "Shoe-Insole-TypeA",
  "display_name": "鞋垫 A 型",
  "total_points": 128,
  "surface_model": {
    "format": "stl",                        // "stl" | "obj" | "gltf" | "glb"
    "file_name": "shoe_insole_A.stl",       // 原始文件名
    "data_base64": "QnJpbmcgbWUgdGhlIGhvcml6b24uLi4="  // 模型二进制数据 Base64 编码
  },
  "cells": [
    {
      "id": 0,
      "center_3d": {"x": 10.0, "y": 8.0, "z": 2.5},
      "normal": {"x": 0.15, "y": -0.23, "z": 0.96},
      "width_mm": 10.0,
      "height_mm": 10.0,
      "rotation_deg": 0.0
    }
  ]
}
```

**字段约束**：
- `version`: 固定 `"2.0"`
- `device_model`: 1-64 字符
- `display_name`: 1-128 字符
- `total_points`: 1-200 整数
- `surface_model.format`: 枚举 `["stl", "obj", "gltf", "glb"]`
- `surface_model.data_base64`: Base64 编码的原始模型文件二进制内容（单文件自包含，无需外部模型文件）
- `cells[].id`: 0 到 total_points-1，不重复
- `cells[].center_3d`: Cell 中心在曲面上的 3D 坐标（mm）
- `cells[].normal`: 曲面法向量（单位向量）
- `cells[].width_mm` / `height_mm`: > 0（正方形约束下 `width_mm == height_mm`，属性面板仅暴露单一边长字段）
- `cells[].rotation_deg`: 0.0-360.0

### FR-16: 3D 扩散模型 (3D Diffusion Model)

#### FR-16.1: 衰减函数
使用与 2D 版一致的**二次衰减（抛物线型）**，在曲面上沿测地线距离计算：
```
对曲面上每个采样点 P：
  d = geodesic_distance(P, cell_center)      // 曲面测地线距离
  R = side_mm / 2                          // Cell 等效半径（正方形统一边长）
  weight = max(0, 1 - (d / R)²)             // 二次衰减
```

#### FR-16.2: 距离计算
- MVP 阶段统一使用 **3D 欧几里得距离** 近似曲面测地线距离：`d = |P - cell_center|₃D`
- 理由：鞋垫等目标曲面较平坦（无 > 90° 弯折），3D 欧几里得距离与测地线距离误差 < 5%
- 后续版本可在高曲率曲面场景下切换为 Dijkstra 测地线计算

#### FR-16.3: 多 Cell 叠加
与 2D 版一致：标量加法叠加（不归一化）
```
contribution_map = Σ (sensor_value[i] * weight_i(P))
```

#### FR-16.4: 颜色映射
使用与 2D 版一致的 Jet 色阶 LUT（256 级 RGBA），绝对值线性映射：
```
color_index = clip(contribution_map * 255, 0, 255).astype(uint8)
color_rgba = Jet_LUT[color_index]
```

### FR-18: 重叠检测与可视化 (Overlap Detection & Visualization)

#### FR-18.1: 重叠定义
两个Cell存在重叠当且仅当它们在曲面上的投影区域（考虑旋转角）有实际相交部分。中心距离只作为快速预筛，不能把仅边缘接近、相邻贴边或间距很小但未相交的 Cell 标红。

#### FR-18.2: 重叠检测算法
- 使用**2mm精度栅格**对曲面XY投影平面进行Cell区域栅格化
- 对每个Cell，将其旋转后的矩形区域栅格化到重叠检测网格中
- 网格单元计数器记录每个位置上的Cell堆叠层数
- 每个Cell取其中心位置的重叠计数值作为重叠度

#### FR-18.3: 重叠可视化
- **3D视图**：重叠Cell的patch和边框采用FR-17.5中的警示色
- **状态栏**：显示 `重叠: N`（N为存在重叠的Cell数量），无重叠时显示绿色`0`
- **通道表格**：新增"重叠"列，显示每个Cell的重叠层数，重叠≥2时红色加粗显示
- **Toast通知**：每次重建Cell后若有重叠，自动弹出警告提示"检测到 N 个Cell重叠区域"

#### FR-18.4: 重叠处理策略
- 碰撞检测开启时：拖拽Cell时阻止重叠（SATP分离轴定理碰撞检测）
- 碰撞检测关闭时：允许重叠，但通过警示色提醒用户
- 属性面板提供 `[碰撞检测]` CheckBox，默认开启

---

### FR-19: 曲面覆盖缺口检测 (Gap/Anomaly Detection)

#### FR-19.1: 缺口定义
曲面上某个区域被视为"缺口"当：
- 该点位于曲面Mask有效区域内
- 该点周围 **15mm 半径内** 没有任何Cell的中心点

#### FR-19.2: 检测时机
- **用户点击"保存"按钮时自动触发**
- 可手动触发（`工具 → 检测缺口`）

#### FR-19.3: 采样策略
- 以 **8mm 步长** 在曲面XY投影上均匀采样
- 仅统计Mask内部的采样点
- 对每个采样点，检查15mm半径内是否存在任何Cell中心

#### FR-19.4: 检测结果展示
- 若无缺口：正常保存，状态栏提示"保存成功 — 曲面覆盖检测通过"
- 若有缺口：
  1. 在3D视口顶部显示**红色警告栏**：`"⚠ 曲面覆盖不足: 检测到 N 处缺口区域 (约X%表面暴露)，当前已放置 M 个Cell"`
  2. 在3D视图中用**红色球体标记**（直径5mm）标注每个缺口位置
  3. 弹出Toast警告"保存警告: 曲面存在 N 处缺口，建议增加Cell覆盖"
  4. 警告栏提供 `[📍 定位缺口]` 按钮（相机跳转到第一个缺口）和 `[✕ 忽略]` 按钮

#### FR-19.5: 缺口处理
- 缺口检测不阻止保存（仅警告），用户可选择忽略并继续保存
- 建议用户在缺口区域手动放置或通过自动填充补充Cell

---

### FR-20: 平面区域检测与自动填充 (Planar Detection & Auto-fill)

#### FR-20.1: 平面区域定义
曲面上的区域被视为"平面"当：
- 区域内相邻采样点的曲面法向量夹角 **≤ 20°**（可配置）

#### FR-20.2: 平面检测算法
- 预计算曲面每个网格点的法向量（基于高度场梯度）
- 以 **6×6网格单元** 为滑动窗口，检查窗口内法向量一致性
- 若窗口内所有法向量与中心法向量的点积 ≥ cos(20°)，则该窗口标记为平面区域
- 合并相邻的平面窗口形成连续平面区域

#### FR-20.3: 自动填充面板
工具栏 `[⬜ 自动填充]` 按钮打开浮动面板，包含以下可调参数：

| 参数 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| Cell 宽度 | 12 mm | 2-50 | 自动生成Cell的宽度 |
| Cell 长度 | 7 mm | 2-50 | 自动生成Cell的长度 |
| 最小间距 | 3 mm | 0-20 | Cell之间的最小间距 |
| 限定平面度 | 20° | 5-60 | 法向量夹角阈值（越小越严格） |

- 面板实时显示 `预估: N 个Cell`
- 预览时在3D视图中用**绿色球体**标记候选放置位置
- 点击 `[⚡ 执行自动填充]` 完成放置
- 点击 `[清除预览]` 移除预览标记

#### FR-20.4: 自动填充策略
- 仅在检测到的**平面区域**内生成Cell（曲面区域的Cell需手动放置）
- 生成网格排列（行列对齐曲面的切平面方向）
- 自动跳过与已有Cell重叠的位置（保持minGap间距）
- Cell使用空闲的最小ID依次分配

#### FR-20.5: 弯曲曲面的手动Cell放置
对于非平面（弯曲）曲面区域，用户通过以下方式手动放置Cell：
- **Ctrl+Click**：在曲面上点击放置新Cell（固定10×10mm正方形）
- **拖出下一个按钮**：从Cell篮子拖出下一个空闲Cell到曲面上
- 手动放置的Cell可后续调整大小、旋转和位置

---

### FR-21: 曲面手动Cell放置 (Manual Cell Placement on Surface)

#### FR-21.1: 快捷键放置
- 按住 `Ctrl` 键时，鼠标在曲面上点击直接放置新Cell（10×10mm正方形）
- 状态栏实时显示Ctrl键状态：`Ctrl: ON (放置Cell)` 绿色 / `Ctrl: —` 灰色
- 仅在编辑模式下生效，预览模式下禁用

#### FR-21.2: 普通点击选中
- 无Ctrl键时，左键点击Cell patch区域选中该Cell（Focus状态）
- 点击曲面空白区域取消选中

#### FR-21.3: 放置约束
- Cell必须在曲面Mask范围内
- 若Cell篮子无空闲ID，提示"Cell篮子已满"
- 放置后自动触发重叠检测并更新颜色显示

## 附录 A: 术语定义

| 术语 | 定义 |
|------|------|
| **Cell** | 传感器通道的物理代理。它在编辑器中锚定一条硬件通道（channel ID）、一个空间位置（重心/顶点）、一个覆盖范围（边长和扩散半径）三者的对应关系，使得主软件拿到原始传感器电压时能准确地把信号值投射到曲面上的正确位置并计算出扩散后的热力图。没有 Cell 这个中间层，传感器数据就是一堆不知道往哪画的数字。 |
| **Channel** | 传感器数据通道编号（0 ~ total_points-1），与 Cell 一一对应 |
| **Surface Model** | 3D 三角网格模型，定义 Cell 可放置的曲面边界 |
| **测地线距离** | 曲面上两点之间的最短路径距离 |
| **法向量** | 曲面上某点的垂直方向单位向量 |
| **Patch** | Cell 在曲面上的参数化四边形区域 |
| **落地 (Landed)** | Cell 已被放置到曲面模型上 |
| **未落地 (Unlanded)** | Cell 尚未放置，仍在篮子中等待拖出 |
| **Focus 状态** | Cell 被选中，进入可编辑状态 |
| **射线检测 (Ray Casting)** | 从屏幕坐标发射射线与 3D 三角面求交 |
| **Orbit 控制** | 围绕目标点旋转、缩放、平移的相机控制方式 |
| **Jet 色阶** | 蓝→青→绿→黄→红的 256 级颜色映射查找表 |
