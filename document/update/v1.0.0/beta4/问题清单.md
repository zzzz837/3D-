## 需求澄清

之前错误理解：把整个模型表面当热力图渲染
**正确理解**：
```
Cell压力 → Wendland重建 → vertexPressure + vertexConfidence → 仅Cell附近顶点着色
```

- **有 Cell 覆盖的顶点**: 显示压力颜色 × 置信度 → 形成"压力斑点"
- **无 Cell 覆盖的顶点**: 保持模型原始灰色 → 空白区域不渲染
- **效果**: 模型上出现 2-3 个彩色压力斑块，斑块之间是原始的灰色模型

---

## 实现方案

### 1. 双通道输出
- `vertexPressure` = weighted sum / weight sum (Wendland 标准)
- `vertexConfidence` = clamp(Σ weights, 0, 1) → 用作 alpha/opacity

### 2. 仅着色有覆盖的顶点
- `weightSum > epsilon` → 设置 vertexColor + 降低该顶点在模型上的不透明度
- `weightSum == 0` → 顶点保持模型原始颜色

### 3. 动态模拟
- 2-3 个高斯热点在 Cell 包围盒内漂移
- 热点赋予周围 Cell 压力值
- 顶点通过 Wendland 查询附近 Cell 得到压力

### 4. 可视化效果
- 模型上形成**可见的彩色圆斑**（对应热点区域）
- 斑块随热点漂移而移动
- 斑块外模型保持灰色 → 与旧 sine wave 完全不同
