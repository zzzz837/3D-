## 1. 算法概述

### 1.1 做什么

输入一组离散压力采样点(Cell)，在 3D Mesh 表面上重建连续压力场，生成彩色热力图。

```
Cell (离散采样点)
    ↓
Wendland C2 加权插值
    ↓
per-vertex pressure (连续压力场)
    ↓
Jet colormap → vertexColors
    ↓
3D Mesh 表面热力图
```

### 1.2 物理模型

将每个 Cell 视为连续压力场的**离散采样点**。对 Mesh 上每个顶点，在影响半径内查询邻域 Cell，使用 Wendland C2 核函数计算权重并做加权平均。属于 **局部加权插值 (Local Weighted Interpolation)**，不是压力叠加。

## 2. 选型过程

### 2.1 候选方案

| 方案 | 类型 | 核心思想 |
|------|------|---------|
| **Wendland C2** | 局部加权插值 | 紧支撑核函数加权平均，顶点受半径内 Cell 影响 |
| **MLS** | 局部曲面拟合 | 每个顶点在邻域 Cell 上拟合多项式曲面 |
| **Graph Laplacian** | 全局扩散 | Mesh 拓扑图上的 Dirichlet 边值问题 |

### 2.2 仿真验证

构建了 5 个仿真框架 Python 文件 (~1500行)，在 5 种测试场景 (均匀/聚类/鞍面/边缘稀疏/极限稀疏) + 真实 3D OBJ 模型上对比：

```
└── output/              # 36个输出文件 (PNG/NPY/CSV/JSON)
```

### 2.3 选型结论

**Wendland C2 选定为主方案**，Graph Laplacian 为稀疏场景备选，MLS 淘汰。

| 淘汰/选择 | 原因 |
|-----------|------|
| ✗ **MLS 淘汰** | 边缘稀疏场景产生 **7 个假峰**（真值仅 1 个）；3D 模型压力**超界 8%** |
| ✓ **Wendland 主方案** | 边缘衰减率 0.90（最佳）；C2 光滑无伪影；紧支撑局部控制精确 |
| ○ **Laplacian 备选** | Cell < 20 的极限稀疏场景更快 (20-40x)；需 Mesh 拓扑支持 |

## 3. 三种候选算法

### 3.1 Wendland C2 核函数 (选定)

#### 核函数

归一化距离 r = d / R（d = 顶点到Cell距离，R = 影响半径 query_radius_mm）：

```
φ(r) = (1-r)^4 × (4r+1),  0 ≤ r ≤ 1
φ(r) = 0,                  r > 1
```

**核心性质**:
- **紧支撑**: r ≥ 1 时严格为零，无硬截断伪影
- **C2 光滑**: r=1 处 φ = φ' = φ'' = 0，全部连续
- **严格正定**: 在 ℝ⁵ 及以下所有维度正定

#### 加权平均公式

```
P(v) = Σ(P_i × φ(r_i)) / Σ(φ(r_i))  ×  min(1, Σ(φ(r_i)))
       ─────分子/分母归一化─────      ───置信度衰减───
```

- **分子/分母归一化**: 消除传感器密度假象（密集区域不偏亮）
- **min(1, Σw) 置信度衰减**: Coverage 不足时自然渐隐，避免边缘硬切

#### 最终着色

```
vertexColor = MODEL_GREY.lerp(jetColor(normalizedPressure), confidence)
```

没有 Cell 覆盖的顶点保持模型灰色，热力图只出现在 Cell 附近。

### 3.2 MLS (淘汰)

最小化加权残差拟合局部多项式曲面：

```
min Σ w_i(x) × (P_i - f(x_i))²
```

一次: f(x,y) = ax + by + c
二次: f(x,y) = ax² + by² + cxy + dx + ey + f

**淘汰原因**:
- 边缘稀疏场景产生 7 个假峰（过拟合）
- 3D 模型压力超界 8%
- 每个顶点需求解最小二乘 → O(K³) 昂贵

### 3.3 Graph Laplacian (备选)

构造 Laplacian 矩阵 L = D - A，求解 Lx = b（Cell 位置为 Dirichlet BC）。

**优势**: 自然适配 Mesh 拓扑，20-40x 快于 Wendland
**劣势**: 需完整 Mesh 拓扑，固定半径的 Wendland 在边缘控制上更优

## 4. 仿真对比结果

### 4.1 2D 合成场景 (5 场景 × 3 算法 × 8 指标)

| 场景 | 指标 | Wendland C2 | MLS | Graph Laplacian |
|------|------|-------------|-----|-----------------|
| uniform_gaussian (120 cells) | RMSE | 7.54 | **4.71** | 7.95 |
| | Runtime | 6972ms | 2264ms | **301ms** |
| clustered_gaussian (100 cells) | RMSE | 44.41 | **19.32** | 24.29 |
| uniform_saddle (100 cells) | RMSE | **4.26** | 5.66 | 4.82 |
| **edge_sparse_multi (58 cells)** | RMSE | **16.41** | 35.38 | 32.24 |
| | **edge_decay** | **0.90** | 0.79 | 0.43 |
| | local_peaks | **1** (正确) | **7** (❌假峰) | 1 |
| sparse_15 (15 cells) | RMSE | 56.33 | 30.37 | **26.97** |

### 4.2 关键发现

1. **边缘行为 (最重要)**: Wendland edge_decay = 0.90，远优于 Laplacian (0.43) 和 MLS (0.79)
2. **假峰控制**: MLSD 在 edge_sparse 产生 7 个假峰 → 直接淘汰
3. **压力保界**: Wendland 和 Laplacian 严格保界，MLS 超界 8%
4. **稀疏场景**: Cell < 20 时 Laplacian 最优，Wendland 出现空洞

### 4.3 综合评分

| 维度 | Wendland | MLS | Laplacian |
|------|:--------:|:---:|:---------:|
| 边缘处理 | ★★★★★ | ★★★ | ★★ |
| 假峰控制 | ★★★★★ | ★★ | ★★★★★ |

## 5. JS 生产实现

### 5.1 核心函数 (可直接复制集成)

```js
// ========== 核函数 ==========
function wendlandPhi(r) {
  // r = d / query_radius, normalized distance
  return r >= 1 ? 0 : Math.pow(1 - r, 4) * (4 * r + 1);
}

// ========== 颜色映射 (Jet colormap) ==========
function jetColor(t) {
  t = Math.max(0, Math.min(1, t));
  let r, g, b;
  if (t < 0.125) {
    const s = t / 0.125;
    r = 0; g = 0; b = 128 + 127 * s;
  } else if (t < 0.375) {
    const s = (t - 0.125) / 0.25;
    r = 0; g = 255 * s; b = 255;
  } else if (t < 0.625) {
    const s = (t - 0.375) / 0.25;
    r = 255 * s; g = 255; b = 255 * (1 - s);
  } else if (t < 0.875) {
    const s = (t - 0.625) / 0.25;
    r = 255; g = 255 * (1 - s); b = 0;
  } else {
    const s = (t - 0.875) / 0.125;
    r = 255 * (1 - s * 0.5); g = 0; b = 0;
  }
  return new T.Color(r / 255, g / 255, b / 255);
}

// ========== 主重建函数 ==========
// 输入:
//   vertices: Float32Array[N*3] — 所有顶点在Cell空间的坐标
//   cells: [{id, x, y, z}] — Cell 对象数组
//   cellPressures: {id: pressure} — Cell 压力值映射
//   fieldRadius: number — 影响半径 (单位同顶点坐标)
//   pressureMin, pressureMax: number — 归一化范围
//   MODEL_GREY: T.Color — 未覆盖区域的底色
// 输出: 直接写入 geometry.attributes.color
function reconstructPressureField(vertices, cells, cellPressures,
                                   fieldRadius, pressureMin, pressureMax,
                                   geo, modelGrey) {
  // Step 1: 构建空间分桶 (加速邻域查询)
  const buckets = buildSpatialBuckets(cells, fieldRadius);

  // Step 2: 遍历每个顶点
  const pos = geo.attributes.position;
  const n = pos.count;
  const col = geo.attributes.color;
  const range = pressureMax - pressureMin || 1;

  for (let i = 0; i < n; i++) {
    const lx = vertices[i * 3], ly = vertices[i * 3 + 1], lz = vertices[i * 3 + 2];
    const nearby = queryBuckets(buckets, lx, ly, lz);

    let num = 0, den = 0;
    for (const cell of nearby) {
      const dx = lx - cell.x, dy = ly - cell.y, dz = lz - cell.z;
      const d = Math.sqrt(dx * dx + dy * dy + dz * dz);
      if (d > fieldRadius) continue;

      const r = d / fieldRadius;
      const w = wendlandPhi(r);
      num += (cellPressures[cell.id] || 0) * w;
      den += w;
    }

    if (den <= 1e-6) {
      // 无Cell覆盖 → 保持底色
      col.setXYZ(i, modelGrey.r, modelGrey.g, modelGrey.b);
      continue;
    }

    const pressure = num / den;
    const confidence = Math.min(1, den);

    if (confidence <= 0.01) {
      col.setXYZ(i, modelGrey.r, modelGrey.g, modelGrey.b);
      continue;
    }

    // 归一化 + 着色
    const t = Math.max(0, Math.min(1, (pressure - pressureMin) / range));
    const jc = jetColor(t);
    const fc = modelGrey.clone().lerp(jc, confidence);
    col.setXYZ(i, fc.r, fc.g, fc.b);
  }

  col.needsUpdate = true;
  geo.material.vertexColors = true;
}
```

### 5.2 空间分桶 (性能关键)

```js
// 将 Cell 按 fieldRadius 网格分桶，顶点查询时只检查所在桶及26个相邻桶
// 复杂度从 O(V*N) 降到 O(V*k), k << N

function buildSpatialBuckets(cells, bucketSize) {
  // 计算包围盒
  let minX = Infinity, minY = Infinity, minZ = Infinity;
  let maxX = -Infinity, maxY = -Infinity, maxZ = -Infinity;
  cells.forEach(c => {
    minX = Math.min(minX, c.x); maxX = Math.max(maxX, c.x);
    minY = Math.min(minY, c.y); maxY = Math.max(maxY, c.y);
    minZ = Math.min(minZ, c.z); maxZ = Math.max(maxZ, c.z);
  });

  // 分配桶
  const dims = [
    Math.ceil((maxX - minX) / bucketSize),
    Math.ceil((maxY - minY) / bucketSize),
    Math.ceil((maxZ - minZ) / bucketSize)
  ];
  const buckets = new Array(dims[0] * dims[1] * dims[2])
    .fill(null).map(() => []);

  cells.forEach(c => {
    const bx = Math.floor((c.x - minX) / bucketSize);
    const by = Math.floor((c.y - minY) / bucketSize);
    const bz = Math.floor((c.z - minZ) / bucketSize);
    const idx = bx + by * dims[0] + bz * dims[0] * dims[1];
    if (idx >= 0 && idx < buckets.length) buckets[idx].push(c);
  });

  return { buckets, dims, origin: [minX, minY, minZ], bucketSize };
}

function queryBuckets(bucketInfo, lx, ly, lz) {
  const { buckets, dims, origin, bucketSize } = bucketInfo;
  const bx = Math.floor((lx - origin[0]) / bucketSize);
  const by = Math.floor((ly - origin[1]) / bucketSize);
  const bz = Math.floor((lz - origin[2]) / bucketSize);

  const result = [];
  for (let dx = -1; dx <= 1; dx++)
    for (let dy = -1; dy <= 1; dy++)
      for (let dz = -1; dz <= 1; dz++) {
        const nx = bx + dx, ny = by + dy, nz = bz + dz;
        if (nx >= 0 && nx < dims[0] &&
            ny >= 0 && ny < dims[1] &&
            nz >= 0 && nz < dims[2]) {
          const idx = nx + ny * dims[0] + nz * dims[0] * dims[1];
          result.push(...buckets[idx]);
        }
      }
  return result;
}
```

## 6. 性能优化架构

### 6.1 问题

手套模型 ~150万顶点。原始暴力方法每次都要：
- 150万次 `getX/Y/Z + applyMatrix4`
- 150万次空间分桶查询
- 150万次 Wendland 核函数计算
- 150万次 jetColor 颜色计算

### 6.2 两层缓存架构

```
┌─ rebuildFieldCache() ─────────────────────────┐
│  触发: Cell增删移动 / 力场半径变化              │
│  一次性 (~2-5s for 150万面)                    │
│                                                │
│  产出:                                         │
│  _vpos: Float32Array[顶点数*3]  顶点坐标缓存   │
│  _cv:   Uint32Array[]            覆盖顶点列表   │
│  _ioff: Uint32Array[N+1]         CSR行偏移     │
│  _icell: Uint32Array[M]          影响Cell ID   │
│  _iwgt: Float32Array[M]          Wendland权重  │
└────────────────────────────────────────────────┘
                      ↓
┌─ applyFieldColors() ───────────────────────────┐
│  手动: 压力变化时  |  模拟: 每500ms             │
│  ~10-50ms (150万面, 仅遍历覆盖顶点)             │
│                                                │
│  只遍历 _cv (覆盖顶点, ~5-10万)                 │
│  读预存的 _iwgt 权重, 只做乘加 + 颜色计算       │
│  无 matrix multiply, 无空间查询, 无Wendland    │
└────────────────────────────────────────────────┘
```

### 6.3 CSR (Compressed Sparse Row) 格式

```
_ioff[i]   → 顶点 i 的第一个影响Cell在数组中的位置
_ioff[i+1] → 顶点 i 的最后一个影响Cell+1

_icell[j]  → 第 j 个影响的 Cell ID
_iwgt[j]   → 第 j 个影响的 Wendland 权重

遍历顶点 i 的所有影响:
  for (let j = _ioff[i]; j < _ioff[i+1]; j++) {
     cellId = _icell[j];
     weight = _iwgt[j];
  }
```

### 6.4 缓存失效策略

| 触发操作 | 失效动作 | 代价 |
|---------|---------|------|
| Cell 放置/移动/删除 | `invalidateFieldCache()` → 全量清灰 | 一次性 |
| 力场半径修改 | `invalidateFieldCache()` | 一次性 |
| 压力值变化 | 仅 `_lastKey = null` (不清缓存) | 零 |
| 模型重新加载 | `_vpos = null; invalidateFieldCache()` | 一次性 |

### 6.5 性能数据 (实测预估)

| 指标 | 150万面模型 |
|------|-----------|
| Cache 首次构建 | 2-5s (一次性) |
| 覆盖顶点数 (_cv) | ~5-10万 (覆盖率 3-7%) |
| 手动模式着色 | ~50-100ms (按需, 无持续开销) |
| 模拟模式着色 | ~10-50ms/帧 (每500ms) |
| _vpos 内存 | ~18MB (150万 × 3 × 4bytes) |
| Influence Cache 内存 | ~5-20MB (取决于覆盖顶点数) |

## 8. 色彩映射

### 8.1 Jet Colormap

```
t=0.000  → 深蓝 (0, 0, 128)
t=0.125  → 纯蓝 (0, 0, 255)
t=0.375  → 青色 (0, 255, 255)
t=0.625  → 黄色 (255, 255, 0)
t=0.875  → 红色 (255, 0, 0)
t=1.000  → 深红 (128, 0, 0)
```

### 8.2 置信度混合

```
最终颜色 = MODEL_GREY.lerp(jetColor(normalizedPressure), confidence)
                                        灰色  ←────→  热力色
```

- confidence = min(1, ΣwendlandWeights) ∈ [0, 1]
- 顶点附近 Cell 越多 → confidence 越高 → 颜色越接近热力图
- 顶点附近 Cell 稀疏 → confidence 低 → 颜色偏向灰色 (自然渐隐)

## 10. 局限性 & 后续方向

### 10.1 当前局限性

| 局限 | 影响 | 改进方向 |
|------|------|---------|
| Euclidean distance | 曲面弯曲处不准确 | 升级为 Geodesic distance (需 BVH) |
| 固定影响半径 | 稀疏区域产生空洞 | 自适应半径 / 降级到 Laplacian |
| Jet colormap 无感知均匀性 | 视觉上蓝-青过渡不明显 | viridis / turbo colormap |
| 无后处理 Gaussian 卷积 | 可能有像素级噪点 | 添加可分离 Gaussian |
| CSR 首次构建慢 (2-5s) | 大模型首次打开有等待 | Web Worker 后台构建 |
| 仅 vertexColors 渲染 | 依赖顶点密度 | 可升级为 texture-based |

### 10.2 推荐后续工作

1. **Geodesic distance**: 沿曲面测地距离替代欧氏距离，消除弯曲表面的误差
2. **自适应降级**: Cell < 20 时自动切换到 Graph Laplacian
3. **Web Worker**: 将 `rebuildFieldCache` 移到 Worker 线程，避免主线程卡顿
4. **Texture-based 渲染**: 用 canvas/GPGPU 做热力图纹理，解耦顶点密度

### 11.3 关键公式速查

| 公式 | 表达式 |
|------|--------|
| Wendland C2 核 | `φ(r) = (1-r)⁴(4r+1), r<1; else 0` |
| 加权压力 | `P(v) = Σ(P×φ) / Σφ × min(1, Σφ)` |
| 归一化 | `t = clamp((P - min)/(max - min), 0, 1)` |
| 最终颜色 | `grey.lerp(jetColor(t), min(1, Σφ))` |
